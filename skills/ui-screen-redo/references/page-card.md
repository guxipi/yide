# 页面卡模板

存到 `013 美术/UI_CARGO/mock/<屏>_redo/page_card.md`。每一栏都要有出处(文件路径、配置表名、代码类名、截图文件名、拍板记忆名);查不到的写「没查到」,不猜。

```markdown
# <屏名> 页面卡  (YYYY-MM-DD)

## 转化目标
- 主转化(一句可判定的话):玩家 ______ 。
- 次要动作(最多两个):……
- 这屏失败长什么样:玩家 ______ 就算没转化(比如看完关掉、点进去又退回)。

## 位置和分量
- 入口:从哪几处进(每处一张截图)。
- 频率:每天几次 / 一次性 / 赛季一次。
- 分量:这件事在游戏里多重(日常小事 / 资源决策 / 付费决策 / 赛季大事)。分量决定版面的分量。
- 进来前玩家刚做完什么,离开后去哪。

## 真数据
- 配置表 / ScriptableObject / 服务端端点:这屏显示的每个数从哪来。
- 真实的边界值:最贵的价格、最长的名字、最多的条目数、最少的条目数。

## 最新实机截图
| 状态 | 文件 | 拍摄日期 |
|---|---|---|
| 默认 | | |
| 空 / 满 / 不够钱 / 已领 / 锁住 …… | | |

## 现有元素全清单
| # | 元素(按钮 / 页签 / 入口 / 角标 / 信息块 / 文案) | 现在做什么 | 截图位置 |
|---|---|---|---|

## 已有拍板
- 这屏或这个系统已经定的事(记忆文件名 + 一句话)。和本次改版冲突的单独标出来。

## 勾哥这次的原话
> ……
```

写完自问一句:如果只给一个从没见过这屏的人看这张卡,他能说出这屏要玩家干什么吗?说不出就回去补。
