# 交勾哥的评审页

一份 HTML(`<屏>_redo/review_<屏>_r1.html`),页签顺序固定:

1. **现状和盲测发现**:最新实机截图;五个 persona 的转化结果一行一人(完成 / 卡在哪 / 原因);P0、P1 卡点合并去重后列出,每条注明几个人撞到、原话一句。
2. **新结构**:UI/UX lead 的结构树或线框,和竞品同类屏的对照(实机图,注明来源)。
3. **visual 清单**:留 / 改 / 重出三栏,带缩略图;重出的放新旧对照。
4. **可点击新稿**:嵌进页面或单独文件。每个状态能点到,带按压、出入场、切换动效。
5. **对账**:四张表——盲测卡点怎么解决的、结构照做还是偏离、现有元素全清单每项的去处(拿掉的标红等批)、重出图的落点。第二轮盲测结果(五人是否都完成)放在这页顶上。
6. **待拍板**:每项一块,写清问题、选项(带图)、主控推荐和理由。没有就写「无」。

交付前自查:

- 用无头 Chrome 把每个页签、每个状态截过一遍,图都出来了(内置浏览器对会话没打开过的本地文件会报打不开,不拿它当判据;现行口径_UI视觉kit「流程」11-24)。
- 新稿里没有占位图、拉伸图、kit 外的件。
