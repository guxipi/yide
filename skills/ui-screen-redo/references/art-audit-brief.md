# 主美派单模板(画风审计)

用 `art-director` agent。它和盲测、UI/UX lead 同时跑,看不到它们的 report。第 2 步合成时如果新结构需要新 visual,再派它出清单或验收出图。

```
你是 Extraction Raiders 的主美。这次只审一屏上的 visual 是否符合现行画风(绝区零 taste + ER 品牌),不改信息结构。

勾哥原话:<贴>

输入(用 Read 打开看):
- 最新实机截图:<路径列表>
- 现行 UI 规矩:vault 01 - 星际拓荒重构/013 美术/AI记忆/现行口径_UI视觉kit.md(读全文,尤其「总方向」「颜色」「面、暗纹和 KV」「图标、名牌、头像、券、位图」)
- 画风基准:功能图标、头像、券和凭证、非 icon 的名牌和底板各对标哪组图,以上面那份现行口径「图标、名牌、头像、券、位图」一节写的为准,打开原图看,不凭描述;件的形和面看 vault 013 美术/UI_CARGO/mock/kit_v12.html 对应的样张

要做的:
1. visual 清单:截图上每一个图像元素一行(图标、头像、名牌、KV、场景底图、底纹、贴纸、进度件、按钮面)——它是什么 / 对标哪个基准 / 判定:留、改(说改哪里)、重出(说为什么、按哪个基准出)/ 截图里的位置。
2. 逐条对现行口径的硬规矩查:薄荷绿、亮黄只给 START、文字描边、三色并排条、纯色头像底、横向拉伸糊图、整张乘色、圆角键、切边 12 设计像素、内容面八成有暗纹或 KV。违反的列出来。

4. 重出清单:要重出或新出的图,每张写用途、尺寸、对标基准、建议工具(功能图标出 2–3 个方向给勾哥挑)。

不做的:不动信息结构和文案;不自己出图(只列清单);不拿被勾哥点名画风不对的图当参考。

交付:写到 <屏>_redo/art_audit.md,回复里给路径和 200 字以内摘要。
```
