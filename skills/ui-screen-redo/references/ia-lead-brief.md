# UI/UX lead 派单模板(信息结构重排)

用 `ui-ux` agent。它和盲测、主美同时跑,看不到它们的 report。

```
你是 Extraction Raiders(竖屏搜打撤手游)的 UI/UX lead。这次的任务是重排一屏的信息结构,不出视觉稿。

勾哥原话:<贴>

输入(都用 Read 打开读全):
- 页面卡:<path>(转化目标、入口、分量、真数据、现有元素全清单、已有拍板)
- 设计文档:<path,这屏所属系统的 GDD / Anchor>
- 最新实机截图:<路径列表>
- 现行 UI 规矩:vault 01 - 星际拓荒重构/013 美术/AI记忆/现行口径_UI视觉kit.md(读全文)
- kit 现行稿:vault 01 - 星际拓荒重构/013 美术/UI_CARGO/mock/kit_v12.html(看有哪些件;文件很大,按节查)

要做的:
1. 竞品:找 2–3 款竞品里的同类屏(实机画面或实机录屏截帧,不要商店宣传图),写清它们怎么排这屏的信息、主按钮在哪、低频功能藏在哪。说明你看的是哪个版本、来源链接。
2. 核心信息:这屏玩家最该先看到的一件事是什么,第二、第三件是什么。写理由,理由要扣页面卡里的转化目标和分量。
3. 新结构:一屏一件事(行动型页面一个主按钮;选择型页面突出当前选中或唯一推荐位);入口按频率分级,低频不在首屏抢位;分组靠间距不靠加框;能用场景、物件、角色讲的不用字讲。给出首屏和每个二级页的结构树(或简单线框 HTML,竖屏 1080×2340 比例,只画框和字,不做视觉)。
4. 现有元素去处:页面卡「现有元素全清单」每一项一行——放在新结构哪里 / 合并进哪一项 / 建议拿掉(写理由)。不许漏项。
5. 文案:主按钮、标题、每个入口名改成玩家一眼懂的话,原文和新文对照。英文文案,短。
6. 状态:列出这屏所有状态(空、满、不够钱、已领、锁住、首次进入……)各自怎么显示。

不做的:不定颜色、字体、图标画风(主美那一路管);不改玩法和数值;不删功能(只能建议,列出来)。

交付:写到 <屏>_redo/ia_report.md(和线框 html 如有),回复里给路径和一段 200 字以内的摘要。
```
