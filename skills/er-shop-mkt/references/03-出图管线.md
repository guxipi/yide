# 03 出图管线

ER 商店 MKT 图有三类,参考图和 prompt 模板各不相同,混了就漂。三类默认走 codex 的 image_gen(勾哥定的,物件图要训到和 er-icon-gen 的 v4 样张一个画风),纯 icon(64 档读图的那种)走 er-icon-gen。

| 模板 | 用途 | 参考图(全部绝对路径) | 尺寸 | 底 |
|---|---|---|---|---|
| A `kv` | 人物 key art(屏头图、弹窗头图) | 2 张定稿 KV + 角色手册定稿板 + 表情表 = 4 张 | 横 1672×941 或竖 1024×1536 | 完整场景 |
| B `object` | 包装、吊卡等物件,任务行动图网格 | 只有 v4 icon 母版 1 张 | 竖 1024×1536 / 网格 1536×1024 | 纯绿 #00FF00 |
| C `card` | 横版人物插画卡面 | 同 A,4 张 | 横 1672×941 | 单色渐变 + 放射 |

参考图路径(vault = `I:\My Drive\Obsidian\ExtractionRaider\01 - 星际拓荒重构\`,换机改环境变量 `ER_VAULT`):

- 定稿 KV 画法基准(勾哥指定的两张横图)、icon 母版、各角色喂哪几张手册图,都写在 `scripts/mkprompt.py` 的 `STYLE_KV` / `V4_ICON` / `BIBLE` 常量里,以脚本为准,不在这里抄第二份。
- 角色手册换了定稿(`013 美术/角色手册/img/`),先改 `BIBLE` 再出图;BIBLE 里只放定稿板和表情表。

## 步骤

1. **对象拆清**。一屏要几张图:人物图几张(A/C)、物件几件(B)。同一屏的兄弟件(三档卡包)必须同一段模板只换颜色,一起出。
2. **光和画法**(只对 A/C)。商店营销不用先拉 mo.co 图(vault `013 美术/mo.co截图/README_参考怎么选.md` 把它列在不拉的一类),直接照定稿 KV 的提取写:人物与单色品牌底同一套冷紫环境光,暗部偏蓝紫不发黑,亮部一层浅色边光,无黑描边,大块平面色两阶明暗,人物占卡高 70~85%。
3. **写 jobs.json**,跑 `py -3 scripts/mkprompt.py jobs.json <工作目录>` 生成 `p_<name>.txt`。字段:
   - card:`hero`、`what`(卡是什么,含数值)、`story`(一句人物在做什么,必须让人一眼读出卖什么,见 02 章"人物插画的画面规则")、`bg`(主色)、可选 `keep`、`prop`(关键道具,自动加"卡中央约 45% 卡高、与人物重叠")、`text`(画面里唯一允许的字;story 必须点名它且写明完整不被挡,AVOID 自动改成只禁其他文字)。kv 也支持 `text`。
   - kv:`hero`、`what`、`story`、`comp`(构图:人物在哪一半、取景到哪、哪一块留给 UI)、`light`(TIME AND LIGHT,按故事定,不许空,脚本会拦)、可选 `size: portrait`。
   - object:`pack: {base, rays, band}`(卡包三档就换这三个色)或 `desc`(其他物件,只写形状和两三种颜色;要留印刷面写 blank plain single-color area)。脚本拦材质词(glossy、chrome、holographic、specular、iridescent、realistic 等)。
4. **跑**:`bash scripts/run_codex.sh <工作目录> <name> <参考张数>`(A/C 填 4,B 填 1)。用 `run_in_background` 后台跑,一次一张、等完成通知再跑下一张(Windows 下并行会挤瘫沙箱,见 `codex-executor` 第 2 节)。脚本跑完自动查 rollout:image_gen 每次调用带的参考 png 数必须等于期望值、没有工具调用打开 direct-extraction-raider-art,不过就 REJECT,原样重跑一次;连续两次 REJECT 停下查原因,不要第三次盲跑。
5. **物件抠绿**:`py -3 scripts/key.py img/<name>.png a/<name>.png`。阈值 spill 90~170 是收紧过的,放宽会把薄荷色部件抠成半透明。
6. **人物抠图**(要出框时):KV 原图留一份当卡片底,另出一份人物 RGBA 叠在上面。W4 做法:用 jobs 的 `cut` 模板让 codex 在定稿图上 EDIT,保留人物和手里道具、其余改纯绿,再 key.py;要一张去掉人物的空底板用 `plate` 模板。这两类参考图只有原图 1 张,run_codex 期望张数填 1。

## 验收门(出图后、进稿前,每张都过)

- **画风密度**:成图和定稿 KV / 手册板缩到同尺寸并排,质感比定稿细(皮肤纹、布料噪点、写实材质)= 打回。物件图和 v4 母版里的仓库 icon 并排,描边粗细和光泽对不上 = 打回。
- **人物身份**:和手册板并排看脸、发型、服装主色、手册里标出的标志物。手数、手指数数一遍。
- **同光**:人物、道具、背景同一个主光方向;暗部冷紫不发黑。
- **留白**:卡面右 40% 能放下大字;KV 指定给 UI 的区域没有杂物。
- **手机档**:缩到 50% 看主物件能不能一眼认出;卡包上的枪在 400px 宽卡包上还认得出是哪把。

## 已知坑(都踩过)

- 物件图喂了 KV 场景图 + 写了 holographic/glossy/specular/chrome/gold foil → 通用手游光滑 3D,画风漂移。只喂 v4 母版,不写材质词。
- 包装正面画剪影枪 → 手机上糊。用彩色枪 icon 合成(gun badge),包装图本身正面留空。
- prompt 写 "Make ONE image_gen call, a NEW image" 而没点名 referenced_image_paths → 参考图根本没进画图模型,人物脸漂。模板第一句必须点名,跑完查 rollout。
- codex 默认会自动加载全局 ER 美术 skill 并改写 prompt(airbrushed/3D-CG)→ 必须 `--enable skip_host_skill_discovery`。这个开关下 `-i` 要绝对路径。
- 不写 TIME AND LIGHT → image_gen 默认晴天白天。夜晚的 BP 舞台、黄昏的柜台都要写明。
- 自己写人物外貌描述 → 盖过参考图(非人角色会被画成人)。只写 "reproduce EXACTLY this character",外貌全靠手册图。
- 手写 codex exec 不关 stdin 会挂住不出图(`run_codex.sh` 已带 `< /dev/null`,通用说明见 `codex-executor` 第 1 节)。判断:log 只有约 39 字节的 `Reading additional input from stdin...`、超过 3 分钟没变,就停掉重跑。
- codex 把参考路径存进变量再 `load()` 传给 image_gen → `check_rollout.py` 数不到,报 `refs=[0]`,其实参考带进去了。模板首句已加「路径写成字面数组」;脚本遇到这种情况会多打一行 NOTE。`check_rollout.py` 认 png / jpg / jpeg / webp 参考。
- 识别色是绿的物件用纯绿底抠图,绿色部件会被抠成半透明:只抠和画布边缘连通的绿,或者换品红底。
