# 02 可复用部件

这里只放跨屏复用的部件和画面规则,不规定某一屏长什么样(10-27 勾哥:"skill 不需要规定具体某一屏幕是什么")。某一屏用哪些件、怎么排,按本次需求、参考图和 tokens 现做。

尺寸一律按 1080 宽手机画布(显示时 0.5 缩放)。UI 外壳的字阶、底色、按钮层级、底纹渐变以 `CARGO_tokens.md` 第十五、十六、十七节为准。CSS 片段来自 W4 稿(`handoff_2026-10-27/design/v3_parts.js`、`v4_parts.js`、`v5_parts.js`),新稿直接复用这些函数,不要重写一套。

## gun badge(包装 / 卡面上的主打件)

彩色 icon 本体,不做剪影(纯剪影在手机尺寸糊成一团,10-27 v4 已否)。三层叠:底下一层同图 `filter:brightness(0);opacity:.55`,向右下错位约 4% 宽当深色影子;上面一层用 `stk(品阶色, 粗细)` 加白边再加品阶色外描;整体 `rotate(-12°~-18°)`,宽占所在面 80~85%。

```js
// v4_parts.js 原样:先白四向再品阶色四向,粗细取宽的 1.2%,最少 3px
const stk = (c,b)=>`filter:drop-shadow(${b}px 0 0 #fff) drop-shadow(-${b}px 0 0 #fff) drop-shadow(0 ${b}px 0 #fff) drop-shadow(0 -${b}px 0 #fff) drop-shadow(${b}px 0 0 ${c}) drop-shadow(-${b}px 0 0 ${c}) drop-shadow(0 ${b}px 0 ${c}) drop-shadow(0 -${b}px 0 ${c})`;
```

品阶色只用 CARGO 第一节六色(Legendary #FC6520 / Epic #9A3CF5 / Rare #3B8BEA …),不要自调。放射底画在包装图里(prompt 写 sunburst of N rays),不要用 CSS conic-gradient 叠,叠出来是平面感。

## 放射底 + 闪星

包装 / 卡面的光感只用两样:印在图里的放射线,和 2~3 颗四角星(`star()`,白色,大小为宽的 7~10%)。不加镜头光晕、不加粒子背景。

## GUARANTEE 角标

卡片右上角一块深墨 #1C1440 底的牌子,下面错位 12px 一条卡面品牌色边,硬投影 `0 10px 0 rgba(0,0,0,.35)`;主字白、副字青,文字加 `text-shadow:0 3px 0`;右侧白底小方块里放卡片或宝石图标。**不要用和卡面同色的色带**(10-27 勾哥:"右上角的角标根本看不出来,要么加 drop shadow 要么换颜色"),对照 mo.co EXCLUSIVE 卡的深墨时间牌 / 价格牌。现行写法见 W4 `board_w4_v5.html` + `v5_parts.js`。

## 价值贴纸

品红 #E806F8 切角小 Tag,+6° 倾斜,压在主物件右上:"x8 VALUE" / "1500%" / "BEST VALUE"。一屏一枚(CARGO 品红贴纸上限的子集)。

## 两段式价值句

价值说明统一句式:"<立刻得> right now, plus <每天得> a day for <天数> days"。数字右对齐到同一条线(第十六节对齐通道)。

## 人物出框 KV

底图一张完整 KV 裁进卡片(`kvIn`),再叠一张抠好的人物 RGBA(`kvOof`,抠图用 `scripts/key.py` 或人工抠)向上抬 120~160px 越过卡片上沿;要压大字的一侧加 `linear-gradient(90deg,transparent,rgba(28,20,64,.9) 30%)` 垫底。人物出框只出头和肩,手和道具不出框(会压到顶栏)。

## 挂板 Supply Rack

墨板底 + 洞洞板圆点(`peg`),商品用金属挂钩(`hook`)挂上去;主推那件大一档、略低、前置。这是"商店是一个地方"的最小实现。

## 任务行

行 = tokens 第五节"行插画位":左侧斜切色块(按行动类型着色,不叠纹)+ 放大出框的行动图(t_extract / t_kill / t_mine / t_build / t_contract / t_upgrade 一类,一个行动一个图)+ 任务一句 + 进度条 + 奖励贴纸 item + 右侧按钮(GO 白 / CLAIM 薄荷);完成行盖勾,锁定行半透明。没有对应行动图的任务先进 er-icon-gen 队列,不拿通用图凑。

## 人物插画(卡面、KV)的画面规则

10-27 勾哥几轮否稿后定的。具体画什么每次按商品的卖点重新想,不照搬上一张:

- 一眼读出卖什么:画面中央有一件直接讲出商品用途的道具或动作,人物和它有互动;人物只是拿宝石摆 pose 不算("卡面的内容……需要有联系,目前读不出来")。
- 动作合人设、合目标玩家的语感:ER 偏 Gen Z,要不屑、轻松、有态度,不要用力、夸张的动作("这个是 Gen Z,想想 gen Z 会怎么做")。没把握时出两版给勾哥选。
- 肢体和服装对手册:两只胳膊从各自肩膀出发,不从背后或躯干后伸出,手册是长袖就不露臂("胳膊是从身后伸过来的")。
- 画里如果要有字,只允许一两个关键字(数字、缩写),必须完整可读,不被手、碎片或特效盖住。

prompt 写法:STORY 里点名唯一允许的字并写明"完整、不被遮挡、不碎";AVOID 把 text 换成 "any writing other than the exact text named in STORY"(`mkprompt.py` 的 card/kv job 填 `text` 字段即自动切换);加 ANATOMY 段写清两臂位置和袖子,出完和手册并排核袖子和手;关键道具填 `prop` 字段。

构图坑:道具生在会被 UI(角标、卖点面板、标题)压住的位置,事后挪图又会切到人脸。prompt 里直接写死道具位置和给 UI 留空的区域,不要靠事后挪图。
