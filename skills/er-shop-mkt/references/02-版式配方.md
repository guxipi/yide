# 02 版式配方

尺寸一律按 1080 宽手机画布(显示时 0.5 缩放)。UI 外壳的字阶、底色、按钮层级以 `CARGO_tokens.md` 第十五、十六节为准,这里只写营销视觉和每类屏特有的部分。CSS 片段来自 W4 v3/v4 现行稿(`handoff_2026-10-27/design/v3_parts.js`、`v4_parts.js`),新稿直接复用这两个文件里的函数,不要重写一套。

## 公共件

**gun badge(包装/卡面上的当周 UP 枪)**。彩色枪 icon 本体,不做剪影(纯剪影在手机尺寸糊成一团,10-27 v4 已否)。三层叠:底下一层同图 `filter:brightness(0);opacity:.55`,向右下错位约 4% 宽当深色影子;上面一层用 `stk(品阶色, 粗细)` 加白边再加品阶色外描;整体 `rotate(-12°~-18°)`,宽占包装正面 80~85%。

```js
// v4_parts.js 原样:先白四向再品阶色四向,粗细取宽的 1.2%,最少 3px
const stk = (c,b)=>`filter:drop-shadow(${b}px 0 0 #fff) drop-shadow(-${b}px 0 0 #fff) drop-shadow(0 ${b}px 0 #fff) drop-shadow(0 -${b}px 0 #fff) drop-shadow(${b}px 0 0 ${c}) drop-shadow(-${b}px 0 0 ${c}) drop-shadow(0 ${b}px 0 ${c}) drop-shadow(0 -${b}px 0 ${c})`;
```

品阶色只用 CARGO 第一节六色(Legendary #FC6520 / Epic #9A3CF5 / Rare #3B8BEA …),不要自调。放射底画在包装图里(prompt 写 sunburst of N rays),不要用 CSS conic-gradient 叠,叠出来是平面感。

**放射底 + 闪星**。包装/卡面的光感只用两样:印在图里的放射线,和 2~3 颗四角星(`star()`,白色,大小为宽的 7~10%)。不加镜头光晕、不加粒子背景。

**GUARANTEE 角标**(充值卡、gacha 主推必有)。卡片右上角一条转 18° 的色带(约卡宽 47%、卡高 41%,一半伸出卡外被裁掉),上面右对齐两行字:上行大 "LEGEND" / "2,100 GEMS" / "MAX",下行小 "GUARANTEE" / "IN TOTAL";右侧一个白底圆角小方块转 8°,里面放卡片或宝石图标。色带用卡面主色的渐变,字白。写法见 `giftCard`,参考 refs 22、24。

**价值贴纸**。品红 #E806F8 切角小 Tag,+6° 倾斜,压在主物件右上:"x8 VALUE" / "1500%" / "BEST VALUE"。一屏一枚(CARGO 第一节品红贴纸 ≤3 的子集)。

**两段式价值句**。卡面或礼包说明统一句式:"<立刻得> right now, plus <每天得> a day for <天数> days"。数字右对齐到同一条线(第十六节对齐通道)。

**人物出框 KV**。底图一张完整 KV 裁进卡片(`kvIn`),再叠一张抠好的人物 RGBA(`kvOof`,抠图用 `scripts/key.py` 或人工抠)向上抬 120~160px 越过卡片上沿;卡片右侧加 `linear-gradient(90deg,transparent,rgba(28,20,64,.9) 30%)` 给大字垫底。人物出框只出头和肩,手和道具不出框(会压到顶栏)。

**挂板 Supply Rack**。墨板底 + 洞洞板圆点(`peg`),卡包和点数卡用金属挂钩(`hook`)挂上去;主推那张大一档、略低、前置。这是"商店是一个地方"的最小实现。

## gacha 卡包

包装:铝箔袋,1024×1536 竖图,顶底锯齿封口 + 挂孔,正面一个放射底面 + 底部五分之一一条空白名带(v4 `pk4_*.png`,prompt 见 03 章模板 B)。三档配色固定:Strategic 紫+橙 / Tactical 钴蓝+青 / Standard 墨绿+薄荷。

正面从上到下:顶部一条品阶色小 Tag "THIS WEEK · <枪名>"(宽 <330px 时省略)→ gun badge 占中部 → 名带写档位名(Saira Condensed Black,宽的 13%,INK)。包装外:右侧信息块 = 档位名 T1 + 墨板小表(保底 "Legendary within 50 opens"、"Epic within 10")+ 两个价签(单抽 / x10)。保底那行用 Legendary 橙。

屏级:商店里三档挂在 Supply Rack;抽卡详情弹窗用主推一档的大包装(宽 ≥420)+ 右侧可能掉落 3 件(品阶边 icon)+ 底部 x1 / x10 两个价签,x10 是主按钮。

## 挂墙点数卡

竖卡 + 圆挂孔 + 挂钩,卡面上半大数字(T1 72 以上)+ 物件图,下半一行说明 + 价签。用于免费每日、低档补给。和卡包同挂在 Supply Rack 上,靠形状区分档次:点数卡 = 日常,卡包 = 抽奖。

## 横版充值卡(月卡 / 免广告 / 终生卡)

卡面 1672×941 人物插画(prompt 03 章模板 C):人物居左 55%,腰部以上,三分之四侧向右,右 40% 平静单色渐变 + 大放射。UI 叠法直接用 `v4_parts.js` 的 `giftCard(y,{art,title,lines,price,badge,band})`(936×560,圆角 32,无描边,10/12px 深色硬阴影):右上一条 18° 斜色带当 GUARANTEE 角标(两行字 + 白底小图标转 8°);左下一条斜切色带写卡名;右下半透明墨板卖点面板写两段式价值句(白字一句 + 青字 "+300 FREE GEMS RIGHT NOW")+ 价签。色带按卡种:月卡紫→蓝紫、免广告深橙→橙。**卡边不要黄色描边**(10-27 勾哥圈掉 v4 早期稿的金边)。

卡下方一张白信息卡逐行列价值(Right now 300 / 60 a day × 30 1,800 / Safe slots +2 / Insurance 1/day),标签 INK_2、值 INK 右对齐。两张卡并列时各配一张,不要合成一张表。

## 新手礼包弹窗(First Extract)

从上到下:人物 KV 头图(高约 520,Rook 抱货箱那张 `kv_rook_cut.png` 出框)→ 礼包名 lockup "FIRST EXTRACT"(倾斜 -4°,白字 + 品牌紫硬阴影)→ 主奖励一块(3rd Safe Slot,物件图 + 一句 "What you put here comes home with you")→ "ALSO INSIDE" 三格(牛皮区块里的白格)→ 选弹药 = 三张枪卡并排(g_smg / g_shotgun / g_sniper 的 icon,选中白底 + 青边 + 上抬 8,未选纸底),卡下只写一个短词 → 价值贴纸 "x8 VALUE" → 一个 BUY 薄荷按钮在拇指区。X 在右上。

## BP(主屏 / 购买弹窗 / 奖励详情)

主屏:顶部当期英雄横版 KV(1672×941 裁 1080×560,英雄居左,右侧 "DECEMBER PASS · 28D" + 英雄名 T1 + 付费内容一行)→ 当前档进度条 → 竖排三列表:

| 列 | 宽 | 底 | 格 |
|---|---|---|---|
| FREE | 约 300 | 白卡 / 纸凹格 | 160 格,图标统一 112 |
| 档位脊柱 | 约 120 | 墨板竖条 | 六边形档位号,当前档青 |
| PREMIUM / MAX | 约 560 | 炫彩 `holo`(115° 紫→品红→蓝紫→青) | 200 格,一档最多两格并排,图标 140 |

行高按付费格走,FREE 格在行内垂直居中。每格图标底统一(白格)、大小统一、裁掉 icon 透明边再放(`object-fit:contain` 前先 trim)。已领 = 紫戳 -3°,可领 = 薄荷边,锁 = 挂锁。英雄碎片格用英雄方头像(不是圆)。底部两个价签:PREMIUM $9.99 / MAX $14.99,MAX 上贴 "+6 TIERS NOW" 品红贴纸。

购买弹窗:头部同一张英雄 KV 缩小版;两张档卡并排,MAX 卡用炫彩底 + 更宽,写 "Everything in Premium, and +6 tiers now"。奖励详情弹窗:顶部英雄 KV 条 + 中间大物件 + 名称 T1 + 一句说明 + 主按钮。

## 7 日

key art 头(代言英雄 + 本周主奖励物件)→ 左侧书脊页签 Day 1~7(竖排,今日页签白 + 青边,已过灰纸,未到纸)→ 右侧当日内容:当日奖励大格 + 当日任务 3 行(每行行动图标 + 一句 + 进度 + GO/CLAIM)→ 顶部或底部一条里程碑轨(积分节点挂奖励物件,终点物件大一档)。Day 7 终点奖励用补给舱/卡包大物件,条纹边(橙白)只给这一处。

## 成长基金

key art 头(Tuba 柜台 + 越来越高的货箱台阶,`kv_tuba.png` 那一张的构图)→ 竖脊柱:左侧等级节点(六边形,已达成填色),右侧每级一行两格 FREE / FUND,FUND 格大一档且炫彩边;每行右侧"已领/可领/锁"状态 → 底部墨板总价值条:"Total value" + 三个物件 + 数字(参考 Seasonal Fair)。购买按钮常驻底部。

## 任务行(任何商业屏里出现的任务)

行 = 纸凹行 + 左侧 96 行动图标(t_extract / t_kill / t_mine / t_build / t_contract 一类,一个行动一个图)+ 任务一句 + 进度 + 右侧白 Secondary 按钮(GO / CLAIM)。没有对应行动图的任务先进 er-icon-gen 队列,不拿通用图凑。
