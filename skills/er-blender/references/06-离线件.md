# 06 离线件:VFX mesh、flipbook、VAT、石头单元

这一页的做法来自调研(光效渲染、环境两个方向),**都还没在 ER 里实测**。第一次用时先做一件 pilot,进 Unity 看过再推广,看完把结论补回这一页。

## VFX mesh 生成器(自写 bmesh)

斩击弧、地面印章环、冲击波环、拖尾、罩子:几十行 bmesh 就能参数化生成。约定:UV 的 U 沿长度方向拉直铺平,贴图 Clamp 不 Wrap,从 -1 滚到 +1;弧形只取约 1/3 圆柱,双面,省面数和 overdraw;顶点 alpha 做淡出和溶解遮罩。UV 和顶点色约定要先和 vfx-production 那边的 Unity shader 对上。付费的 Mesh Generator Pro 不值得买。

## 卡通爆炸

归一化 cube-sphere(不用 UV 球,两极顶点不会聚集),Blender 只出细分好的球,顶点色或 UV2 放随机种子;形变在 Unity shader 里做:沿法线噪声位移,顶部涨得更快,溶解靠透明度淡出。局内 VFX 默认半透明 / 叠加发光,只有碎片、宝石这类实物做不透明实心件(可以用 clip 硬裁溶解);颜色和节拍的规矩见 vault `013 美术/AI记忆/现行口径_怪Boss与局内VFX.md` 第 8 节。手游上仍要控制 overdraw(层数、屏幕面积、粒子数)。

## flipbook 打包

film_transparent + EEVEE + Standard 逐帧渲,numpy 按 N×M 拼图(2048 图 9 列每帧约 227px,镜头要拉近让主体填满格)。能灰度就灰度,分通道打包(R 明暗、G 不透明度或噪声、B 溶解、A 形状遮罩),颜色到引擎里给。Blender 存的是直通 alpha,拼图前用 numpy 把边缘颜色往外扩一圈,否则出暗边。

## VAT(OpenVAT pilot)

OpenVAT(GPL-3.0 核心,Unity URP 包 MIT)把几何节点或模拟的形变烘成位置贴图加 remap JSON 加带 VAT UV 的 FBX,交给 GPU 播放,适合大招碎裂和冲击波形变。VAT 贴图导入要无压缩、无 mip、sRGB 关、NPOT None。Unity 6000.3 URP 下能不能用没验,先做一个 pilot。

## 石头单元库(SDF 体素节点)

Blender 5.x 的 Mesh to SDF Grid → SDF Fillet(圆凹角)/ SDF Grid Offset 先胀后缩(圆凸角)→ Grid to Mesh → 减面 + 平滑法线,能出地标巨石和石块;按 00 的语言收:保留几块大平面和明确转折,圆角只收棱,不做成鼓胀的鹅卵石,避开以前被判"破碎"的 noise 位移做法。只用于圆润石头;崖本体(不倒圆)和薄棱角碎石不走这条。体素网格三角多而均匀,必须减面。批准的节点树用 NodeToPython 存成 .py 进复刻做法库,换环境只改参数。项目里 Geometry Nodes 还是零使用,第一件要先摸坑。
