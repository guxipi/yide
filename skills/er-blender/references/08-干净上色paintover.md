# 08 paint-over 管线:给模型上色,任何场景复用

画法标准只有一份:`00-造型与笔触标准.md` 第二、三节(mo.co 车辆语言)。在干净固有色上加稀疏、宽扁、不透明、顺结构的硬边手绘块面,只动同色相明度;环境 hue、光照偏色、AO、投影、溢光不进底色,交给 Unity。这一章只讲怎么把这套画法做出来:选手段、跑管线、过门、避坑。交件自查按 `09-POI交付前检查表.md` §四。

## 先选手段(按效果,不按工具能力)

| 要画的东西 | 手段 |
|---|---|
| 固有色、棱边上的短条提亮、个别面的局部面状提亮、拼块材料的块间差 | 顶点色 `scripts/paintover/po_vertex.py`,按面硬边 |
| 大面内部的斜矩形、楔形块面 | 贴图(本章五步,或真 UV 手绘);顶点色画不了面内的块,不为它把网格切密 |
| 玻璃、屏幕、招牌、涂鸦、海报、标识、贴花 | 贴图;玻璃的反射交给 shader 或受控遮罩,底色里不烘彩色反光条(画法见 09 §四「玻璃」) |
| 小件、圆件、斜放件(原木、岩包、翻倒的车、环) | 顶点色 + LabLit(`_VertexColorMul` 1);要面内笔触就混一张小贴图 |
| Tripo 件 | 已有 UV:真 UV 手绘或本章投影;画法同样按 00 |

一个件可以混用:顶点色给固有色和棱边短条,贴图只铺需要大面笔触的几块面。

### 顶点色 po_vertex.py

```bash
"$B" -b <件>.blend --factory-startup -P $S/po_vertex.py --python-exit-code 1 -- --palette palette.json --out <件>_vc.blend [--prefix SQ_HQ_] \
    [--strip 1.07] [--strip_frac 0.4] [--plane 1.05] [--plane_frac 0] [--block 0.05 --block_classes floor_tile] [--grad 0] [--bands 7.5,11.0]
```

或 `import po_vertex as PV; PV.paint(objs, list(palette), palette)`。`Col` 每次从 palette 重建,跑两次结果一样;glow_ / glass / screen / decal / sign 类跳过(走贴图)。默认值就是 00 的画法:固有色平铺;倒角棱按整条棱(连在一起的窄面)为单位,选约 40% 提亮 7%,朝上的棱优先,同一条棱要么整条亮要么不亮,不出随机斑点;每个角点的颜色都是底色乘同一个系数,色相不动。没有朝向明暗(顶 / 侧 / 底不同亮度 = 烘了方向光),整面渐变默认关。

- `--plane_frac`:局部面状提亮,在面积大于 `--plane_min`(默认 0.25 m²)的面里按面挑一部分整面提亮,默认 0;要用从 0.1 起试,并排看像不像顺结构的块面,像棋盘就关。
- `--block_classes`:块间差只对精确点名的拼块材料类开(palette 类名是颜色名,别猜);kitlib 每个盒子都有自己的 `blk`,连续墙不许按 `blk` 拆成几块明暗。
- `--grad` / `--bands`:整面渐变只在设计需要时开;`--bands` 只能给在檐带、楼板这类几何断开处,给在连续墙面中间会切出横向台阶。

### 贴图:原理

在 Blender 里把模型按固定视角正交渲成"画布"(只有固有色 Emission,不乘 AO、不打任何光,纯绿底)→ terra 在画布上原位上色 → 配准回画布 → hardhue 纠意外色漂 → 每个面挑最正对、看得见它的视角,把画投影回 UV → 每类物件出一张图集。

上色单派 terra(`gpt-6.1-terra`,勾哥按成本定),不派 sol;`run_codex.sh` 默认是 sol,命令里必须带 `CODEX_MODEL=gpt-6.1-terra`。image 1 永远是本张画布,terra 在它上面原位改、版式不动,颜色就是画布上的颜色(= 无 hue 概念图本色)。可选参考两种:`prompt.card` = 本件自己的拆件格,只学笔触放在哪、多疏多密;`prompt.style_refs` = mo.co 笔触参考(首选 vault `013 美术/mo.co截图/车辆语言基准_20261127/` 的原图或裁区),只学笔触形状、大小、疏密和顺结构的放法。两种参考的提示词都写死「颜色、色调、光照、阴影、环境色只看 image 1」,回图照常跑 hardhue 和 `img_colorcheck.py`。发光件写进 `prompt.lights`,只在发光件自己身上画亮芯 + 自身色边,不往墙面、地面、邻件画光(铁规 0);周围的光交给 Unity 的灯和 emission。

分工:贴图这一路的生图由 codex terra 画;顶点色、程序化笔触、shader 这类路线由 Claude 做,能出 00 那种笔触就算数。不许拿占位色块冒充上色交付;Claude 出底稿、配准、投影、验收。看图验收必须亲眼看。

**ER 的游戏镜头不转**(V5:从南 46° 俯视;换了镜头就按新镜头定主视角)。所以主视角就是"游戏镜头方向的正交视图 G",再补 E/W 侧视(0.6 倍密度,只在屏幕边缘斜着看到);朝北的面永远不上屏幕,不画。这样画的正好是玩家看到的那一面,张数也只有六面全画的一半左右。

### 贴图:五步(脚本在 `scripts/paintover/`)
```bash
B="<blender.exe>"; S=<yide>/skills/er-blender/scripts/paintover; W=<工作目录>; CFG=<配置>.json
"$B" -b <场景>.blend --factory-startup -P $S/po_canvas.py --python-exit-code 1 -- --cfg $CFG --out $W     # 1 底稿
py -3 $S/po_prompts.py $CFG $W                                                                             # 2 提示词(末行打出每单参考张数 N = 1 + card + style_refs 张数,也写进 refcount_<set>.txt)
cat $W/joblist_<set>.txt | xargs -P 4 -I{} env CODEX_MODEL=gpt-6.1-terra bash <yide>/skills/er-shop-mkt/scripts/run_codex.sh $W {} $N # 2 terra 上色(放进一个 run_in_background;不带 CODEX_MODEL 跑出去的是 sol)
py -3 $S/po_register.py $W --set <set>                                                                     # 3 配准 + 门(绿色 / 黄绿物件加 --strict-key;稀疏侧视 ECC 发散加 --identity)
py -3 $S/po_hardhue.py $W <sheet> ...                                                                        # 3.5 纠意外色漂:轮廓内逐像素 a/b 换回底稿(多色分件跟着底稿保留)、保留 terra 画的 L(笔触);和底稿差 > 24 的(本模型的灯)保留;`--lock-l` 连 L 一起换回 = 抹掉笔触,只在笔触画坏时用;po_colorlock(按类锁到 palette)不默认跑
"$B" -b <场景>.blend --factory-startup -P $S/po_project.py --python-exit-code 1 -- --cfg $CFG --work $W   # 4 投影 + 图集
"$B" -b <场景>_painted.blend --factory-startup -P $S/po_review.py --python-exit-code 1 -- --out $W --groups "标签=前缀"  # 5 评审图
py -3 $S/po_board.py <板>.png 2 760 "之前" a.png "之后" b.png ...                                          # 对照板
```

### 贴图:配置(样板两份:`examples/j01v7_bh_booth.json`(哨亭)、`examples/j01v7_mine_m1.json`(矿点 M1,带 extra / palette))
| 字段 | 说明 |
|---|---|
| `set` | 名字;画布叫 `<set>_00.png`… |
| `groups` 或 `group_prefixes` | 一起画、互相遮挡的物件。母舱 = 壳 + 支脚一组;遗址每块残件一组;小件每件一组 |
| `views` | 默认 `["G","E","W"]`;也可以 `S N E W T` 六面正交 |
| `ppm` | 主视角像素密度。V5 实机约 71~77 px/m;首批用过:母舱 62、遗址 70、小件 110、有顶屋 89 |
| `side_ratio` | 侧视密度系数,默认 0.6 |
| `underlay` | `col` = 顶点色 `Col`(我们 kit 生成的件);`material` = 物件原有的底色或贴图(Tripo 件、外来件) |
| `prompt.what / colors` | sheet 上画的是什么;要保留的固有色(灰写死 NEUTRAL grey, NOT blue/violet) |
| `prompt.style_refs`(可选) | mo.co 笔触参考图路径列表(相对配置文件或绝对路径),每张 sheet 都喂;提示词写死只学笔触形状、大小、疏密、顺结构的放法,不学形、色、色调、光照、环境色。首选 `车辆语言基准_20261127/` |
| `prompt.lights`(可选) | 本模型自己的发光体、什么颜色、**按件的真实坐标写位置**(例:「帽顶红灯,水平居中、离上边约 2/3」);提示词要求只在发光件自己身上画亮芯 + 自身色边,**不往任何别的面染光**(铁规 0,见 09);独立灯件在墙上什么都不画。不写且 palette 无 `glow` = 本张无光源 |
| `prompt.card`(可选) | 本件自己的拆件图 / 设计格格子路径(字符串 = 所有张共用,或 dict 张名 → 路径),只学笔触放在哪、多疏多密,不学形和色;要么每张都给要么都不给(refcount 一套一个数);颜色写进 `colors`,布局说明写进 `extra` |
| `prompt.extra`(可选) | `{sheet 名: 一句补充}`,例如「深灰方块是关着的金属检修盖,不是窗」 |
| ~~`prompt.marks`~~ | 已作废(旧做旧画法)。配置里还写着会直接报错退出 |
| `palette` | `{类名: "#RRGGBB"}`,**填从没有 hue 的概念图本色取的色**(勾哥定;白模 Col 也用它);发光件类名写 `glow`(有它且没写 lights 时按默认发光描述)。po_vertex 和 po_colorlock 也用它 |
| `fallback`、`atlas_scale`、`cut_m` | 第三轮兜底(默认开)、图集缩放(默认 0.75)、长面切段(默认 1 m) |

参考:人造物外形只挂我们认可的概念图 / 场景图;画法对标 `车辆语言基准_20261127/`(见 00)。`贴图风格基准/moco清透感_20261109/` 只用来看「固有色干净、不发灰」,不当笔触基准。

### 贴图:门(全部要过)
1. **terra 门**:`run_codex.sh` 自动核 rollout,参考图张数必须等于 po_prompts 打出的 N。REJECT 原样重跑一次;连续两次 REJECT 停下查原因。
2. **配准门**:`po_register` 判 PASS = 仿射配准后轮廓吻合度 ≥ 0.965,且 Lab 色漂 < 12(正常的 sheet 实测 0.970~0.999)。
3. **内部漂移,必须人看**:轮廓门看不出"轮廓里的东西被挪了"(例如屋顶俯视是个矩形,肋画歪了也照样 PASS)。每张 sheet 和画布上下叠着看一遍。
4. **评审门**:46° 全景、3/4、游戏距离各一张,前后对比;再和 `车辆语言基准_20261127/` 原图并排,按 00 第五节逐项写差在哪(平面与倒角、体块、笔触是不是稀疏宽扁顺结构的硬边块面、安静区域够不够、固有色稳不稳、底色里有没有 AO / 投影 / 环境色 / 溢光)。刷毛颗粒、厚涂、乱线、密集划痕、做旧、每条边一圈亮线、投影拼接处的明暗跳变,有就重画。hardhue 后同一部件两端各取一次色,色相差肉眼可见 = 没锁住;找到一处漂移整个 POI 每类材质一起扫。硬锁后实机增益要重标。有绿色、有品红(没投上的面)、有错位的竖纹 = 回去查,不交。
5. **引擎门**:paint-over 完**直接放进游戏地图里这个 POI 的实际位置测**(勾哥:「paintover 后直接放入实际地点测试,而不是再放到某个样板间里面」),不进样板间;在实际地点的真光照、V5 镜头下截图(两阶 toon 只是近似 LabLit),周围地面、路、植物和邻居建筑一起入镜。LabLit 只吃这一张底色图。

## 坑(都踩过,大多已在脚本里处理)
| 坑 | 症状 | 根因与做法(脚本里已处理) |
|---|---|---|
| 一个面横跨多格 | 屋顶出绿块、不存在的肋 | 面的中心落在半格里,两端却伸到别的格。投影前沿世界 X、Y 每 1 m 切开,并要求整个面落在格内 |
| 被挂件盖住角的面 | 货匣端面没上色 | 只要多数采样点可见就算可见,护角盖住采样点后被判成看不见。改成三轮:严格(中心 + 多数角点)→ 宽松(只看中心)→ 兜底 |
| 被前景挡了一半的面 | 门楼发光环被抹到旁边的小面上 | 宽松规则太松。先过严格轮,严格轮挑不出视角才降到宽松 |
| 侧面正好与主视角平行 | 肋旁一条条浅色竖纹 | E/W 视角被相邻肋挡住,主视角又看不到这个面。兜底轮:取最正对视图里投影位置的颜色 |
| 画布边缘抗锯齿混进绿色 | 倒角上一圈绿线 | 只信任内缩 3 px 的内部,向外延 40 px 留边;去绿只在边缘 8 px 带里做,否则苔藓绿、绿灰扣带会被洗成灰 |
| `mesh.materials.clear()` | 没投上的面渲成图集颜色(满屏绿) | 清材质会把所有面的 material_index 重置成 0。换材质一律按槽位原地替换 |
| 多个物件在 blend 里重叠 | 遗址互相"挡住" | 遮挡只在同一组内判 |
| 前台 shell 里 `cmd &` 起 codex | 任务被杀,没出图 | 并行一律放进一个 `run_in_background` 命令里,用 `xargs -P 4` |
| 打包只填当前行 | 45 张 sheet | first-fit 打包后 24 张 |
| 深色件被画成藏蓝 | 单件好看,和同套件放一起对不齐色 | `prompt.colors` 写死本套深色件的中性灰色值(例:「中性石板灰 #465C6D / #606F84,NOT navy, NOT blue」) |
| joblist 写成 CRLF 换行 | xargs 拿到"名字\r",找不到提示词,全部 REJECT | po_prompts 改成只写 LF |
| 底稿画了方向光 | 进游戏明暗算两遍 | 底稿只有固有色(`po_blender._flat_emission`,不乘 AO);提示词禁 AO、内角 / 挑檐下压暗、方向光和投影;笔触只做同色相明度变化 |
| 后台 Blender 建不起 GPU 上下文 | EEVEE 渲染直接崩:`nvoglv64.dll` EXCEPTION_ACCESS_VIOLATION,栈在 `DRW_gpu_context_create`;换 Vulkan、PowerShell、关沙箱都一样,旧 blend 也崩 | 设环境变量 `ER_BL_CPU=1`:`po_blender`(底稿)、`po_review`、`kit/review.py` 改用 Cycles CPU。底稿是纯固有色 Emission(无 AO),结果和 EEVEE 一致;评审的两阶 toon 改按 N·L 分阶,**没有投影**,只能看形和色,进 Unity 后真光照再看一次 |
| 单个小件独占一张画布 | 生图模型把它画大一圈、位置下移,配准 0.78 不过(例:固定环 300 px/m) | 提高 ppm 让物件占满画布(同一件 380 px/m 后 0.970 通过);多件同套时按主题分 set,各写只含本 set 的 what |
| `py -3 -c print(...)` 生成的名单管道给 xargs | 每个名字带 `\r`,Blender 找不到物件 | 管道里加 `tr -d '\r'` |
| 同组互相遮挡串色 | 帽顶印上仪器头的色、根上沾绿 | 遮挡在组内判,挂件 / 叶冠这类会挡住主体的件和主体同组就会互相串。会挡主体的件单独成组 |
| 颜色离抠像绿太近 | 叶 #3F8B3E 画亮一点就被 key_mask(G>140 且 G-max(R,B)>70)当背景抠掉,补洞后斑驳 | 新色板先过 key_mask 这条;叶改 #3A8A5A(偏青)后亮版也安全 |
| 稀疏 sheet 上生图模型另画物件 | 照参考图另画一张概念拆件图,或在空白处加画物件 | 提示词已含"只在图 1 轮廓内上色、不加不删任何部件、轮廓外不画";多画在轮廓外的直接抹回纯绿(投影不用) |
| ECC 仿射在稀疏侧视 sheet 上发散 | IoU 配准后反降(0.927→0.908),一次拉成 0.18 | `po_register.py --identity`(跳过 findTransformECC,仿射取单位阵) |
| 重叠薄片被生图模型画成一片 | 两两重叠的叶子画成一片一条主脉,投影后叶脉 / 叶缘错位,轮廓门看不出 | 叶片、旗、板片这类会互相叠的薄片件拆成每片一个物件,一片一组单独画 |
| 绿色物件被去溢色压暗 | 绿叶整圈叶缘变暗青灰;亮叶绿又被当背景抠掉(补洞 16 万 px) | `po_register.py --strict-key`(背景只认近纯 #00FF00,去溢不碰高红像素)。先分"只贴图 / 只光照 / 合成"三张并排,定是贴图还是光照再改 |
| 黄绿凝胶被 key_mask 当背景 | 画亮的凝胶(#A0F030 一类)被抠成洞,边带去溢把小凝胶球压成橄榄色 | 同上 `--strict-key`;凝胶类在 palette 里单列 |
