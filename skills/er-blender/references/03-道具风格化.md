# 03 道具风格化:先在生成端做对,Blender 只按症状修

Tripo 道具、武器、HOME 家具、POI 件要过 ER 画风门。结论先说:**不要对 Tripo 硬表面件默认跑"减面 → 平滑 → 倒角 → 色彩归并"那套 Blender 后处理**。2026-10-26 用两把通用枪(手枪、霰弹枪)做了两轮 A/B,十个变体没有一个在"刻面更少、结构不糊、色块干净、面数不超"四条上全面赢过 Tripo 原模。旧版 skill 写的"五步"在已入库的这两把枪上其实一步都没做过,原模直接进了游戏,看起来反而是最干净的。

## 两轮 A/B 证明了什么

对照组 A 是入库成品(拓扑和 Tripo 原模完全一样,约 9.5k 三角)。量法见 04(white 模式 46° 刻面值、IoU、体检)。

| 做法 | 结果 |
|---|---|
| 40° 按角度标锐边 + 倒角 Harden Normals + Weighted Normal | 比原模更差:Tripo 表面本来有起伏,被标成硬边,刻面值 +7~8%,倒角让面数翻倍,窄处出退化三角 |
| Data Transfer 把原模法线投到成品上(mix 1.0) | 刻面最少(-21~24%),但护木沟槽、套筒防滑纹被抹软 |
| 真减面到 2500 三角 + 60° 锐边 + 先平滑再标锐边 | 面数和刻面值都低于原模,但结构边一起丢了,沟槽糊成一团,握把交界冒星状尖刺;collapse 把 UV 拉坏,贴图在套筒下沿、扳机拖影 |
| 2500 三角再倒角 | 面数 +51~70%,刻面反而略升,还多出退化面和开放边;不值 |
| 逐面 k-means 归到调色板 | 色界跟着三角边走成锯齿,还把 Tripo 烘死的 AO 当成独立颜色(深灰拆成 2~3 档) |
| 按 UV 岛分区取中位色 | Tripo 的 UV 岛不按固有色切,一件拆出 15~16 色,错色面积约 11%(枪口橙色漫到套筒上) |

刻面值这个数字会骗人:平滑和投法线都能把它压低,代价是结构变糊。判结论一定要看 white 和 lablit 的 46° 近景图,不能只看数字。

## 现在的做法

1. **生成端先做对**(Tripo Studio 网页版):正向写 `stylized cartoon game asset, smooth rounded chunky forms, large clean colour areas, simple two-tone painted shading, minimal surface texture, mobile game asset`,反向写 `low poly, faceted, flat shaded, hard facets, black outline, realistic, high detail, PBR, weathered, greebles, noisy texture`。比例矮胖、大形体两三个;先看剪影缩略图,斜俯视认不出的直接重 roll,别指望后期救。网页上如果有低模/面数控制和新贴图模型的选项,用生成端控制面数,不在 Blender 里减(网页实际有哪些选项以当次核对为准;这组生成端 A/B 列在前沿调研表 B02)。
2. **进 Unity 先试零成本层**(gaoguang-3d):"肉感"、软塌多半是法线问题,importer 用 Calculate、smoothing angle 从大往小试,以截图看不出面为准;发灰、塑料感走材质 remap。
3. **Blender 只按症状修**,修之前先用 stage.py 出原模的评审图,修完同机位并排:

| 症状 | Blender 里做什么 |
|---|---|
| 网格坏(开放边、非流形、穿插) | `_er_bl.inspect` 定位,按距离焊点(Tripo 的 UV 缝是断开的,一件常有 1.5k 个重合点)、补洞;不做全局减面 |
| 面数确实超预算 | 优先回生成端控面数;非要在 Blender 减,只减不影响剪影的大平面区,减完看 white 图沟槽和 UV 拖影 |
| 尺寸、比例、原点、朝向不对 | 等比缩放到米制、原点底部中心、按 05 导出;不要非等比缩放 |
| 某一块颜色明显不对 | 只改那块的贴图(按部件遮罩改),不对整件做聚类归并 |
| 武器要挂手 | 加命名 Empty(见 05) |

4. **自己建模的简单件**(不是 Tripo 出的,比如 HOME 家具的箱体、POI 拆件):这类件本来就是大面、少色,可以直接用单材质色板 UV 和竖向渐变(顶亮底暗),家具格子限定客舱六色;这条还没在 ER 实测,第一次用先做一件对照。

## 什么时候回头重试 Blender 后处理

只有出现了原模解决不了的具体问题(比如某件 Tripo 输出刻面肉眼可见、生成端怎么调都不行),才针对那一件试局部投法线(只投大曲面、mix 0.5~0.7,保留结构边)。试之前先读这一页的表,别重走 10-26 已经走过的路。实验脚本和两轮全部产物没进 skill,结论以这一页为准。
