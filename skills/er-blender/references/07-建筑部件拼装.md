# 07 建筑与联邦小件:先做部件,再按设计坐标拼

2026-10-30 勾哥定:POI 建筑优先在 Blender 里做,先拆成墙、门框、屋顶、壳段等部件,再组合起来;建筑直接落在地面上,**不做地板**(也不做印章基座);部件库 Claude 直接做,不派 sol。首批 J01 做完后勾哥评价"建筑和小物件建模非常棒"。产物和完整记录在项目 `ArtWork/J01_POI_Kit_20261030/README.md`。

脚本在 `scripts/kit/`(全部 `blender -b --factory-startup -P <脚本> -- 参数`)。它们是 J01 的生成器,换场景照着改参数或抄结构,不要从零再写。

| 脚本 | 做什么 |
|---|---|
| `kitlib.py` | 调色板(壳白 #C6CFDD / 面板灰 #606F84 / 深色 #465C6D / 发光 #8DFCF5 ≤5%)、`Part` 拼装器(盒、挤出截面、环、柱、拱顶截面)、倒角(Bevel 2 段 + harden normals)、顶点色 `Col`、布尔切口 |
| `build_sc.py` | 有顶屋:按 `pilot.json` 的墙段、门洞、房间、家具坐标拼整栋;分 Low / Up / Roof / Doors / Furniture 五组 |
| `hull.py` + `build_hulls.py` | 破损横卧舱生成器(穿行通道、两端破口、无顶、高壳留远侧、侧翻变体) |
| `build_ruins.py` | 遗址残件直接按设计多边形原位生成:横卧舱残壳条、立筒半壳、平台残脚板 |
| `props.py` / `furniture.py` / `build_props.py` | 16 种联邦小件和 6 种室内家具,尺寸从组件表读 |
| `review.py` / `board.py` | 两阶 toon 评审出图、对照板 |

## 做法
1. **先读三样**:设计数据(房间、墙线、门、组件尺寸和坐标)、过审概念卡、mo.co 截图(红线⑥,记下提取写进工作目录 `notes/`)。
2. **设计数据和参考图不一致时,以设计数据为准**(勾哥 10-31)。尺寸、高度、比例、房间、门、组件坐标都按数据;参考图只管数据没写的造型和画法。设计数据自己前后矛盾时(J01 有顶屋:pilot.json 写 6 m 墙加双坡顶,story_pass 写"拱顶长屋")才问勾哥。
3. **部件分组按游戏行为切**:有顶屋的墙和门框在 1.2 m 处拆成上下两件,屋顶单独一组。进屋时隐藏"屋顶 + 1.2 m 以上"这两组,就是试点要求的"屋顶淡出、墙裁到 1.2 m"。关闭的门板单独成件。
4. **落地不做地板**:墙和脚墩向地下多伸 0.3 m,防地形起伏露缝。
5. **大门放不进低檐时做"人口"门楼插件**:凸出墙面的门楼块,用布尔把拱顶在通道处切开(23 总纲 DNA2)。
6. **画风**(mo.co 提取):直边大块,倒角约为短边的 4~6%,不鼓不圆;靠分块缝、腰线、压顶读结构;缝的底色要浅(J01 用 #8E9BB0),深色缝在游戏距离下会读成黑描边。
7. **出图**:每件出 46° 全景、3/4、游戏距离(屏宽 14 m)三张,橙色 1.52 m 胶囊当 Wren 标尺,和概念卡、mo.co 同尺度拼成对照板,亲眼看过再往下。

## 坑(J01 实际踩过)
| 坑 | 症状 | 做法 |
|---|---|---|
| 两个盒子顶面共面 | 顶上出现斜向刻面、闪烁(z-fighting) | 部件顶面错开高度;门楣和门柱不要同时覆盖同一块,门柱只到门高,门楣盖满 |
| 墙段在拐角、T 型交接处重叠 | 交接处闪烁 | 每个端点和交叉点放一根略粗的立柱盖住 |
| 色块抖动按"块序号"取值 | 同一块墙在 1.2 m 上下两半颜色不一样 | 抖动按块的平面中心算(z 不参与) |
| 绞盘、卷盘露出滚筒 | 读成绞盘机关(设计明令禁止) | 全封闭外壳,只露端盖 |
| 母舱南墙(镜头一侧)太高 | 挡住南侧设备带 | 镜头一侧的残墙压低;远侧屋顶残片不会挡 46° 镜头,可以放心做宽 |
| 残墙断口用尖锐锯齿 | 不像 mo.co 的块状断口 | 平台阶 + 短斜角,偶尔一个缺口 |

## 照参考建小件:先逐块写清,再同角度同区域核(10-31 工具箱打回 6 轮的教训)
勾哥:"对参考的刻画不够仔细,总是丢掉或是增加一些细节"。根因三条:看个大概就按常识搭(多了锁扣槽、上部包边,漏了整高竖条);只看整体缩略图验收;被打回只补点到的那一处。更上游的一条:这几轮一次都没加载 `reference-replicate`(它 10-16 就写好了同样的根因和 refkit 尺子),自己临时写脚本绕远路。所以**先加载 reference-replicate**(skill 闸会拦),下面四步是它在小件上的补充:
1. 动手前把参考裁出局部、放大,逐块写一行:是什么、从哪到哪(地面/箱沿/半高)、凸出还是凹进、挨着谁、参考里**没有**什么。只建这张表里的东西。
2. 每轮用 `scripts/kit` `closeup.py`按参考的角度出同一区域的放大图,和参考裁图左右并排,逐行对表。
3. 被打回时回到第 1 步重核整块,不只补点到的那处。
4. 参考的比例和设计数据冲突时以设计数据为准,不用问(10-31 工具匣保留 1.4×0.8)。
5. 先用 `refkit.py measure` 量关键比例再搭(三脚架第一版腿长只有头宽 2 倍,参考是 4~5 倍,一量就知道);先定姿态和开合状态(倒地/立着、开/关)。
6. 勾哥的打回很短时,先在图上圈出理解的位置问"是这里吗"再改("四角没有包边"被我理解反,白做一轮)。
7. 白模形状没过,不进 paint-over。
