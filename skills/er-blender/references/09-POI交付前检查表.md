## 铁规 0(11-10 勾哥,强制执行,压过本表其它任何条目)

**生图时画面里每样东西都是它自己的本色。** 楼(F / D 都算)、屋顶、地面、草、树、岩、水、道具、家具、车、植物,没有例外。灯光、时段、氛围、阴影都不能改任何东西的颜色:不罩整图色调(淡紫 / 暖黄 / 偏蓝都不行)、阴影不带色、发光件只画自己亮、不往别的面染色。HEROES / dirF / dirD / mo.co 只学形、材质、厚墙语法和收尾质感,**不学被光染出来的颜色**。外观 / 室内 / 俯视 / 拆件 / 方向图 / paint-over 全部适用。勾哥原话:「这个你记在 skill 里面生图的时候主体什么颜色就是什么颜色,绝对不要做出,例如灯光使得 F 类楼体是淡紫灰这种事情,强制执行」「仅仅是 F 类楼体吗?」(11-10 中 POI r2 楼体发紫、草发暖就是违规)。
**少用粉色、紫色**(11-10 勾哥「减少粉色,紫色的使用,这个主要是男生玩的游戏」):固有色里粉 / 紫 / 品红 / 丁香只给极少数功能件,楼体、屋顶、大面积材质不用。
**不许并排多色彩条**(11-10 勾哥「类似这样的彩虹不要出现,这个让人联想 arc raider 有侵权风险」):三条及以上不同颜色并排的条 / 块(青 + 黄 + 红这类),柱身、车身、墙、牌子、线路图、导向牌、地面标线都不许;改单色色带,线路图一种主线色 + 站点亮点,导向牌一个色块 + 白箭头。概念图 / 拆件图里有就按本条改,不照图建;工单 AVOID 写 rainbow / multi-colour stripes。
**怎么强制**:发单前跑 `scripts/imagegen/prompt_lint.py <工单...>`(缺本色段 / 出现 lavender、tint、glow halo、purple-grey shadow / 风格参考没写「只学形和质感」→ 退出码 1,不发);图回来跑 `scripts/imagegen/img_colorcheck.py <图...>`(中性面偏色 / 粉紫占比超标 → 退出码 1,不交)。

## 头号教训(这四类各被纠正 3 次以上)

## 一、设计(拆件表 / 方案)

- [ ] **风格分类**(11-06,11-10 按铁规 0 改):联邦 / 市政 / 工业 / 科研楼 = F(楼体本色 = 中性浅色混凝土 / 暖灰 / 米白,点缀色来自发光件自身和职业功能色,不是来自光照染色);民用 / 商业 / 居住 = D(楼体用沉稳的民用本色:沙色、赤陶、灰绿、石板蓝、奶白、木色;**不用粉 / 紫 / 丁香当楼体色**;花箱、屋顶花园照旧)。没有「共用淡紫灰影」这回事,阴影和色调归 Unity。
- [ ] **方向图不是零件库**(11-09):广告屏、竖灯箱、空调外机、水箱、粉车、雪糕筒、灯笼串、条纹布篷,只有本 POI 设计表明列且和职业相符时才出现;两个 POI 不共用同一组氛围件。小件 = 本 POI 的职业件(灯塔的浮标 / 系缆桩,矿点的岩芯管 / 凝胶桶……)。拆件表逐件问「这件是方向图带进来的,还是这个地点自己的」。
- [ ] **拆件要多、一眼认得出、外形不雷同**(11-09)。
- [ ] **按游戏内物理空间设计**(11-06):位置、朝向、路口、邻居按实地;外形不必贴现有脚印,放得进 plot、不 awkward 就行。
- [ ] **屋顶六层语法**(11-09,`POI外观重设计方案_20261106.md` §1.2):L0 屋面色 ≠ 外壳色、受光 L ≤ 88;L1 压顶换皮、南沿必有东西;L2 / L3 本职业设备 + 一件主角件上屋顶;L5 吞没。屋面任一 6×6 m 不单色。
- [ ] **外墙分段**:踢脚 / 墙身 / 檐带明度分开;V5 看得到的两面要有开口或挂件。
- [ ] **大 POI**(11-06 / 11-07):外观 + 内部都出图;楼上**可以走**;室内照 mo.co 公寓 / diner 的陈设密度和真实感,但要曲折、有搜打撤的复杂感、有 hidden room;外墙可厚,外面有围栏 / 机房 / 彩灯这类件。
- [ ] **室内能走能跑、放精英**(11-10 勾哥「角色和怪进去要能走能跑，不要穿模，中型 POI 一般会在室内放置 1 - 2 精英怪」):门洞、走廊、家具间距按 NavMesh agent 半径留足(按会进来的最大体型怪算),家具不堵通路、不穿墙;中型 POI 室内写清 1–2 个精英放哪个房间、守什么,房间够精英活动和玩家走位。
- [ ] **不沿楼脚 / 墙边放小植物**(11-06,整类删);窗下花箱、屋顶种植箱可以。叶子只长在树上,不单独摆棕榈叶 / 大叶片。
- [ ] **设计结果进看板 8791 `#scene-refs`**(11-06「md 没有人看」);建模进度页先核对是哪一页(HB 改错过 8790)。

## 三、建模(Blender)

**流程**
- [ ] **一轮 15 分钟**(11-09,07「小 POI 一轮 15 分钟」):拆解单(每件 `why` / `cell` / 尺寸;`conflicts`、`absent` 写全)→ `blockout.py` → `overlay.py` 俯视 + g46 叠图 → 细节 → 出图。说不出用途的件不建;叠图没过不做细节;超时说卡在哪一步。
- [ ] **目的是单件精准**(11-09):每件对着拆件图那一格单独做、单独渲、左右并排;复用件库里没有就照格新做,不放占位块。摆位和概念图的小偏差不纠结,不把坐标同步回设计数据。
- [ ] **植物路由**(11-09 拍板):灌木 Blender 逐片叶建;树冠走 Tripo;地形上的植物和崖不在这里做(Unity 编辑器 + codex)。
- [ ] **有机件先做单元**(11-09):灌木先交单片叶和参考叶并排,过了再拼环(5–6 片一环绕枝、相邻环错开,顶上 3 片相交)、再拼整丛;不用穹顶 / 球团 / 叶卡冒充。
- [ ] 不会建的先 research(液体、凝胶、绳、木),不拿一眼不像的件收工(11-09 M2)。
- [ ] 面数按预算(S ≤ 300 / M ≤ 1200),但不为省面降质量;面数不够先说。

**墙与结构**(11-07 HB)
- [ ] 墙是混凝土整浇:无分板缝、无缝条、无装饰横线;每层每段一整块实体,门窗洞布尔挖。
- [ ] 墙垛只在两墙相交处(外墙转角 / 隔墙顶外墙),每层按本层隔墙放;外立面柱只往外凸。每个凸出物说得出用途,说不出删。
- [ ] 窗台不低于剖切高度;墙顶一个颜色(蓝黑),墙垛顶同色。
- [ ] 与平台同高的那级踏步并进平台;楼梯上不许有接缝。
- [ ] 外露棱倒 6 cm / 2 段;家具倒 7 cm / 2 段。不比 mo.co 更圆、更软糯(红线 4)。

**屋顶**(11-09 LOG「我最不能接受的就是这个夹心饼干一样的房顶」「为什么还有绿色的土色」)
- [ ] **平顶不做夹心饼干**:屋面色从边到边铺满整个顶面,墙顶不另起一圈压顶色;顶棱只留一道 5 cm、45° 的硬斜棱(同屋面色),竖角照常圆;不做 0.2–0.3 m 的大圆角带(J01 黄日下削成黄白高光 + 半补偿紫线)。屋面走顶点色(LOG `log_final.py` 的 `VC_ONLY={"roof"}`),色照参考图。南沿雨棚 / 挑檐 / 灯盒离檐口 ≥ 0.4 m,读成门头不读成又一层屋顶。拆件格里画的大圆角顶棱照这条改成硬斜棱。
- [ ] **屋顶吞没(L5)只用立体件**:叶团(5–6 叶环 + 错半步二环 + 顶 3 片交叉叶)、垂藤、真有体积的堆;不贴平面苔斑 / 污渍片 / 扁盘(实机读成「绿色的土」「平橙盘」)。屋顶不单调靠本职业设备件,不靠给屋面分层或描边。
- [ ] **屋顶细件(管、筒、杆、灯杆)进 W1 关投影**(`shadowCastingMode Off`),否则灰屋面上压出一道道紫影条;大体块照常投影。小件别落在大件投影里。

**件**
- [ ] **有门 / 有盖的件和桌子都能打开**(11-09;11-10 勾哥「桌子也要做成 container」:抽屉 / 桌面翻板可开):门扇 / 盖子 / 抽屉单独成件、轴心在铰链、墙上开真门洞、箱子做空心;出关 / 开两态,开态内部也上色;进 Unity 挂 `LootableContainer` + `LootContainerLidVisual`。拆解单里标「容器」。
- [ ] 筒形建筑(灯塔)内部空心可放东西;开盖箱的盖要有真实结构(托盘盖 + 铰链)(11-09 LH)。
- [ ] 绳、木头靠纹理读:绳画股纹,木头画木纹 / 年轮;不做细直管 + 顶点色格子、不做平涂圆柱(11-09 LH)。
- [ ] 楼梯 / 栏杆 / 细杆斜放件:整件灰钢顶点色,不进 paint-over 投影;开口踢面透出地板也算错(11-09)。
- [ ] 家具和地面拉开明度和色相(11-07)。
- [ ] 花坛石圈整块连续(下段墙 + 外挑压顶),不切砖、不做砖缝(11-09 PARK)。
- [ ] 岩块:SV2 定为 r2 光滑圆顶;M2 的岩包要重建、不能是光滑椭球。**改岩块造型前先拿单件图问勾哥**(11-09)。
- [ ] 散件不 AI 排布:不等距一条线、不对称扇开,要像人手放下 / 自然长出(11-09 M1)。
- [ ] 小件不因「实机才 20 px」简化建模或跳过上色(10-31)。
- [ ] **小件逐件和参考格并排 + 写不同点**(11-10 勾哥「把建模和参考图放在一起对比,说出哪些点不同」;只管小件,楼体按坐标 / 平面,不逐条比):同角度、中灰底(白件要看得清),结构先写(由哪几部分组成、数量、弯扭方向、支架怎么接、比例),每条标 已改 / 故意不同 / 待改,不许写「基本一致」。
- [ ] **单件盲认**(11-10 勾哥「这种看不出来是什么的不应该给通过」,TS 天线碟做成平白圆板):每件单件渲图改中性文件名,给没上下文的子 agent 只问「这是什么物件」,说不出 = 重做;盲认原话写进清单。总控审板先遮标题自问「这是什么」。
