## 头号教训(这四类各被纠正 3 次以上)

1. **paint-over 只加明暗,不碰色相**(11-09 一天纠五次)。见 §四。
2. **按 V5 46° 俯视做,不按拆件格的平视做**:玩家看的是屋顶 + 南沿 + 两面外墙(BH 哨亭逐件做对、进游戏只剩白盒子,整个重做)。见 §一、§三。
3. **没把参考看懂、拆清楚就开建**:先拆解单 → 体块 → 叠图,叠图没过不做细节;单件对着拆件格做到像。见 §三。
4. **自己放过可见瑕疵,让勾哥当质检员**(HB 一天被点 7 次):交付前按件类全量过、一个根因全局扫、看见的不放过。见 §六。

## 一、设计(拆件表 / 方案)

- [ ] **风格分类**(11-06):联邦 / 市政 / 工业 / 科研楼 = F(楼体中性浅色,颜色来自灯光);民用 / 商业 / 居住 = D(粉彩楼体、条纹布篷、花箱、屋顶花园)。全部共用 HEROES 范本的淡紫灰影。
- [ ] **方向图不是零件库**(11-09):广告屏、竖灯箱、空调外机、水箱、粉车、雪糕筒、灯笼串、条纹布篷,只有本 POI 设计表明列且和职业相符时才出现;两个 POI 不共用同一组氛围件。小件 = 本 POI 的职业件(灯塔的浮标 / 系缆桩,矿点的岩芯管 / 凝胶桶……)。拆件表逐件问「这件是方向图带进来的,还是这个地点自己的」。
- [ ] **拆件要多、一眼认得出、外形不雷同**(11-09)。
- [ ] **按游戏内物理空间设计**(11-06):位置、朝向、路口、邻居按实地;外形不必贴现有脚印,放得进 plot、不 awkward 就行。
- [ ] **屋顶六层语法**(11-09,`POI外观重设计方案_20261106.md` §1.2):L0 屋面色 ≠ 外壳色、受光 L ≤ 88;L1 压顶换皮、南沿必有东西;L2 / L3 本职业设备 + 一件主角件上屋顶;L5 吞没。屋面任一 6×6 m 不单色。
- [ ] **外墙分段**:踢脚 / 墙身 / 檐带明度分开;V5 看得到的两面要有开口或挂件。
- [ ] **大 POI**(11-06 / 11-07):外观 + 内部都出图;楼上**可以走**;室内照 mo.co 公寓 / diner 的陈设密度和真实感,但要曲折、有搜打撤的复杂感、有 hidden room;外墙可厚,外面有围栏 / 机房 / 彩灯这类件。
- [ ] **不沿楼脚 / 墙边放小植物**(11-06,整类删);窗下花箱、屋顶种植箱可以。叶子只长在树上,不单独摆棕榈叶 / 大叶片。
- [ ] **设计结果进看板 8791 `#scene-refs`**(11-06「md 没有人看」);建模进度页先核对是哪一页(HB 改错过 8790)。

## 三、建模(Blender)

**流程**
- [ ] **一轮 15 分钟**(11-09,07「小 POI 一轮 15 分钟」):拆解单(每件 `why` / `cell` / 尺寸;`conflicts`、`absent` 写全)→ `blockout.py` → `overlay.py` 俯视 + g46 叠图 → 细节 → 出图。说不出用途的件不建;叠图没过不做细节;超时说卡在哪一步。
- [ ] **目的是单件精准**(11-09):每件对着拆件图那一格单独做、单独渲、左右并排;复用件库里没有就照格新做,不放占位块。摆位和概念图的小偏差不纠结,不把坐标同步回设计数据。
- [ ] **植物路由**(11-09 拍板):灌木 Blender 逐片叶建;树冠走 Tripo;地形上的植物和崖不在这里做(Unity 编辑器 + codex)。
- [ ] **有机件先做单元**(11-09):灌木先交单片叶和参考叶并排,过了再拼环(5–6 片一环绕枝、相邻环错开,顶上 3 片相交)、再拼整丛;不用穹顶 / 球团 / 叶卡冒充。
- [ ] 不会建的先 research(液体、凝胶、绳、木),不拿一眼不像的件收工(11-09 M2)。
- [ ] 面数按预算(S ≤ 300 / M ≤ 1200),但不为省面降质量;面数不够先说。

**墙与结构**(11-07 HB)
- [ ] 墙是混凝土整浇:无分板缝、无缝条、无装饰横线;每层每段一整块实体,门窗洞布尔挖。
- [ ] 墙垛只在两墙相交处(外墙转角 / 隔墙顶外墙),每层按本层隔墙放;外立面柱只往外凸。每个凸出物说得出用途,说不出删。
- [ ] 窗台不低于剖切高度;墙顶一个颜色(蓝黑),墙垛顶同色。
- [ ] 与平台同高的那级踏步并进平台;楼梯上不许有接缝。
- [ ] 外露棱倒 6 cm / 2 段;家具倒 7 cm / 2 段。不比 mo.co 更圆、更软糯(红线 4)。

**屋顶**(11-09 LOG「我最不能接受的就是这个夹心饼干一样的房顶」「为什么还有绿色的土色」)
- [ ] **平顶不做夹心饼干**:屋面色从边到边铺满整个顶面,墙顶不另起一圈压顶色;顶棱只留一道 5 cm、45° 的硬斜棱(同屋面色),竖角照常圆;不做 0.2–0.3 m 的大圆角带(J01 黄日下削成黄白高光 + 半补偿紫线)。屋面走顶点色(LOG `log_final.py` 的 `VC_ONLY={"roof"}`),色照参考图。南沿雨棚 / 挑檐 / 灯盒离檐口 ≥ 0.4 m,读成门头不读成又一层屋顶。拆件格里画的大圆角顶棱照这条改成硬斜棱。
- [ ] **屋顶吞没(L5)只用立体件**:叶团(5–6 叶环 + 错半步二环 + 顶 3 片交叉叶)、垂藤、真有体积的堆;不贴平面苔斑 / 污渍片 / 扁盘(实机读成「绿色的土」「平橙盘」)。屋顶不单调靠本职业设备件,不靠给屋面分层或描边。
- [ ] **屋顶细件(管、筒、杆、灯杆)进 W1 关投影**(`shadowCastingMode Off`),否则灰屋面上压出一道道紫影条;大体块照常投影。小件别落在大件投影里。

**件**
- [ ] **有门 / 有盖的件都能打开**(11-09):门扇 / 盖子单独成件、轴心在铰链、墙上开真门洞、箱子做空心;出关 / 开两态,开态内部也上色;进 Unity 挂 `LootableContainer` + `LootContainerLidVisual`。拆解单里标「容器」。
- [ ] 筒形建筑(灯塔)内部空心可放东西;开盖箱的盖要有真实结构(托盘盖 + 铰链)(11-09 LH)。
- [ ] 绳、木头靠纹理读:绳画股纹,木头画木纹 / 年轮;不做细直管 + 顶点色格子、不做平涂圆柱(11-09 LH)。
- [ ] 楼梯 / 栏杆 / 细杆斜放件:整件灰钢顶点色,不进 paint-over 投影;开口踢面透出地板也算错(11-09)。
- [ ] 家具和地面拉开明度和色相(11-07)。
- [ ] 花坛石圈整块连续(下段墙 + 外挑压顶),不切砖、不做砖缝(11-09 PARK)。
- [ ] 岩块:SV2 定为 r2 光滑圆顶;M2 的岩包要重建、不能是光滑椭球。**改岩块造型前先拿单件图问勾哥**(11-09)。
- [ ] 散件不 AI 排布:不等距一条线、不对称扇开,要像人手放下 / 自然长出(11-09 M1)。
- [ ] 小件不因「实机才 20 px」简化建模或跳过上色(10-31)。

**出图核**
- [ ] 建完先出 Blender V5 46° 图看屋顶和两面外墙,再出拆件格角度的并排。

## 四、上色(paint-over)

- [ ] **画法 = mo.co 清透感**(11-09):一块一色 + 一道大柔渐变 + 柔亮边(11-09 晚 LOG:按本件参考图的质感画,不规定顶亮底深;不画 AO / 内角 / 挑檐下压暗 / 投影;每种材质的质感写进 extra),同色相深浅不掺灰,面上不画非几何的缝 / 网格 / 石缝,无笔触、无做旧。06 哨亭作废;PARK 的 painterly 提示词不抄。
- [ ] **生图默认只喂底稿一张(N=1)**(11-09 晚):清透感画法写成文字;不喂 mo.co 图(`style_refs` 报错退出)。要体现参考图质感时可加 `prompt.card` = 本件自己的拆件图格子(N=2),只学质感不学形和色,画完必跑 hardhue。
- [ ] **参考图(无 hue 概念图)什么色,成品就什么色**(不调色相、不整体加深加饱和);提示词写死「image 1 的颜色就是批过的颜色,不加紫 / 粉 / 暖 / 蓝偏色」;浅低饱和色(混凝土)写 COLOUR LOCK + 色值。
- [ ] **画完硬锁色相**(11-09 第五次纠正):`scripts/paintover/po_hardhue.py <work> <sheets>`,轮廓内每像素 a/b 换回底稿、只留 L;和底稿差 > 24 的(本模型的灯)保留。softlock 只当辅助。硬锁后实机增益重标。
- [ ] **验收不只看平均 hex**:同一面左右两端各取一次色,色相差肉眼可见 = 没锁住。找到一处漂移,整个 POI 每类材质都扫一遍一起改。
- [ ] **不画环境光**(11-09):extra 开头写 NO ENVIRONMENT LIGHT,点名本 POI 仅有的发光体;光晕只在紧挨发光体约 1 m 内;其它件逐个点名「只保留固有色 + 柔渐变」。
- [ ] **所有发光件都在 paint-over 画光**(11-09):门边灯条、路灯头、广告牌、屏、亮窗——亮芯近白 → 饱和色边,光画到朝向它的面上;光晕位置按件的真实坐标写进提示词。独立发光件写「它是单独物件,墙上只画淡光晕,不画灯本身」(否则双灯带)。小发光件单开高密度 set(420 px/m)。光池可按几何补(`J01v7_WS2_20261109/gen/po_emitter_pool.py`)。
- [ ] 灯色(蓝 / 琥珀)不涂成固有色;盖子里面和盖子同一种灰(11-09)。
- [ ] 木头干净平涂,只留板缝(11-09 驳船「笔触太多」);但按材料出质感:布像布、木头像木头(11-07)。
- [ ] terra 乱画的三种 sheet 在 extra 写死(稀疏 sheet 另画拆件图 / 俯视大平面画上整个塔正面 / 柜背板补画隔板和货)。
- [ ] 细件投影后跑 `J01v7_WS2_20261109/gen/po_degreen.py`,评审图不许有绿。
- [ ] **顶棱不画亮带**:屋顶顶棱在提示词 `edge_rule` 写死「不画亮带 / 暗线 / 边框」(棱上柔亮带的质感规则不用在屋顶顶棱上)。
- [ ] **投影后跑归属检查,防串色**(11-09 HB「这些地方应该都是实体墙,不要出现这些乱七八糟的纹路」):游戏里会隐藏的屋顶 / 迎镜侧墙,连带藤蔓、吊车环、天窗灯,挡在实体墙前会把颜色印到墙上。跑 `ArtWork/J01v7_HB_v2_20261107/gen/hb_po_owner.py` → `hb_po_bleed.py --fix`(实体面被别的颜色族占 > 8 % 退顶点色,外来颜料按同组回填)。光晕(paint-over 画的和 glow_spill 烘的)先问「这灯会不会跟着某件隐藏」,会隐藏的灯只照它自己那一件。
- [ ] 提示词发出前对一遍现行铁规(旧要求和新铁规冲突以新为准或先问)。
- [ ] 上色派 terra,不派 sol(11-07)。

## 五、进 J01 实地

- [ ] **先删旧 POI 整个根,再放新的**(11-09);旧根上的搜点(loot prefab)不跟着删,在新件位置重新挂上、隐藏网格。
- [ ] **直接放进 J01 这个 POI 的实际位置测**,不进 HBLab / JungleLab 样板间(11-09)。
- [ ] **颜色目标 = 没有 hue 的概念图本色**(11-09 勾哥拍板,见 §七-2):增益标定把实机受光面还原到概念图本色。邻居 POI 的实机色不再当目标,只用来查同类材质有没有明显不像同一种东西,不像就回到概念图本色找原因、问勾哥。量法 k-means k=3 + 最亮 15 % 中位,CIE76 ΔE ≤ 10,出对照板。
- [ ] **光影不动,按现行光反推材质**(11-09 最终口径「现在我决定了光影不动,你要根据光影反推 paintover 让它最终呈现参考图的颜色」):LOG 做法 `gen/log_meas.py` 取点 → `log_calib.py` → `log_final.py` 按「材质 × 色类」增益(`PO:<mat>:<CLASS>`)→ 装 W1 实拍,循环到每个点和参考差 ≤ 10。**阴影的 hue、影面偏紫、顶面过曝归光影会话**(全局 `_LabShadowTint`、LabLit 软肩 `_LabKnee`),POI 侧发现了转告,不在材质里补、不在贴图里烘阴影。
- [ ] **对色截图同一次 Play、同一光**:要比的几家在同一次 Play 里连拍,板上写 t / storm_blend / fog / sun。跨 session 截图只看布局不比色。审色只认对照板数字。
- [ ] **增益按「材质 × 色类」分,不按法线做顶面补偿**:旧 BH 的顶面 TG 蓝增益会在圆角上裂出紫线、把深色钢压成黑块,`topcomp.py` 默认不开。散料(木屑)不跟原木共用增益;浅色大顶面和高饱和小件各给一份系数,不用一组全局系数。
- [ ] **受光顶面过曝闸**(11-09「这个未来不能再出现」):两通道 ≥ 248 或三通道 ≥ 225 = 洗白 = 不交。修法归光影会话(软肩),POI 侧不按组压暗材质;卡住就在交付里明说。
- [ ] **大面积换主色先给 2–3 个引擎色样问**(棚 A 参考是粉紫,勾哥要航空灰)。
- [ ] 45 m V5 实拍看屋顶 + 两面外墙再交。

## 七、11-09 勾哥拍板的三条路由(原先互相冲突,已定)

1. **POI 植物**:**灌木逐片叶建(Blender),树冠走 Tripo**(网页版 Studio,进 Blender 减面 / 烘色后和硬表面件合成一件)。
2. **颜色源头 = 没有 hue 的概念图**(本色图):取色从无 hue 的概念图 / 拆件图本色取。带色调的图不取色;不再以「邻居 POI 实机色」当颜色目标。进引擎后光影不动,按现行光反推材质增益只为还原这个本色(差 ≤ 10);同一 Play 同一光的对拍、按材质 × 色类分标、过曝闸照旧,阴影 hue 和过曝的修法归光影会话(11-09 最终口径)。
3. **地形上的植物、崖**:走 Unity 编辑器 + codex 合作,不进 Blender、不走 Tripo。
