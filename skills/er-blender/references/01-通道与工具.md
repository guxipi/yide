# 01 通道与工具:live 用 MCP 迭代,出货用 blender -b

ER 的 Blender 活有两条通道,分工固定:live 通道(Blender MCP)只用来边改边看、单件迭代;出货通道(`blender -b` 后台脚本)负责导入、修改器、烘焙、导出、验收门和批处理。验收证据只认后台渲到文件的对照板加数字,MCP 截图只算迭代过程。

## 配置

| 项 | 值 |
|---|---|
| Blender | 路径因机器而异(`F:\Apps\blender.exe` 或 `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`),先 `ls` 确认,版本以 `--version` 为准;官方 MCP 要求 ≥5.1 |
| Claude Code 的 blender MCP | 官方 Blender Lab MCP。server 源码 clone 在 `C:\blender_mcp`,`~/.claude.json` 配置 = `<uv 全路径> --directory C:\blender_mcp\mcp run blender-mcp`(user scope);写 uv 全路径,裸 `uv` 可能因 PATH 未刷新 CONNECTION_CLOSED |
| Blender 里的插件 | extension `bl_ext.user_default.mcp`(release 页的 `mcp-<版本>.zip`,用 `blender.exe --command extension install-file -r user_default -e <zip>` 装);默认 localhost:9876,自动启动(延迟 1s) |
| 必开偏好 | Preferences → System → Network → **Allow Online Access**(`bpy.app.online_access`);没开插件静默不起 socket,命令行可用 `--online-mode` |
| 社区版 MCP | ahujasid `uvx blender-mcp` 和官方版同占 9876,不能并存;本机已换官方版 |
| Tripo 桥插件 | addons 下有 `Tripo3d_Blender_Bridge`,默认没用(Tripo 默认走网页版,见下),想试可以试 |

官方版工具按用途分:读场景 `get_objects_summary` / `get_object_detail_summary` / `get_blendfile_summary_*`;执行 `execute_blender_code`;看图 `get_screenshot_of_area_as_image` / `get_screenshot_of_window_as_image` / `render_viewport_to_path` / `render_thumbnail_to_path`;查文档 `search_api_docs` / `search_manual_docs` / `get_python_api_docs`(随包带离线 API 和手册 RST,治 5.x API 漂移);跳转 `jump_to_*`;另有 `*_for_cli` 变体在后台 Blender 里打开 .blend 跑同样的事(代码要给 `result` 赋 dict,超时 120s,读 `BLENDER_PATH`)。它没有一键多角度 `look`,也没有资产库;多视角回看用 `execute_blender_code` 调 `scripts/blender/stage.py` 渲到文件,再读图。写派单时工具写全名 `blender:<tool>`。

## 开工前三件事

1. 先调 `get_objects_summary`。连不上就是 Blender GUI 没开、插件没启用或 Online Access 没开,别反复重试;请勾哥开 Blender GUI,或者直接改走后台通道。
2. 官方文档声明代码执行"没有任何防护",LLM 生成的代码能删数据、能联网;不要在 Blender 里开着和任务无关的重要文件。
3. 写 bpy 拿不准先 `search_api_docs` / `search_manual_docs`,不要凭记忆写 5.x 已改名的 API(见 02)。

## 后台通道写法

```bash
<blender.exe> -b --factory-startup <file.blend 可省> -P script.py --python-exit-code 1 -- <参数>
```

参数从 `sys.argv` 里 `--` 之后读;`--factory-startup` 不吃本机偏好和插件,结果可复现;设置类参数放在 .blend 文件名后面(打开 blend 会覆盖前面的设置)。脚本异常退出码非 0,外层据此判失败。每个入口脚本只有一个 `main(argv)`,结果打一行 JSON 到 stdout,这样同一个脚本在 MCP 里 `importlib.reload` 后也能直接调。

纪律:GUI 会话和后台进程不能同时写同一个 .blend;**不要关别人开着的 Blender GUI**;重要 .blend 别只留在 scratchpad(会丢)。

## Tripo 默认走网页版

默认用浏览器里的 Tripo Studio。tripo-cli、直接调 API、桥插件都可以试,先拿一件和网页版同输入对比。网页操作法、验身步骤见 er-character-pipeline `references/03-Tripo网页操作.md`;点数不记不对账。API/CLI 文档里的新选项(rig v3.0、smart low poly / P2、texture v3.5 delight、segment),以网页上实际有的为准。
