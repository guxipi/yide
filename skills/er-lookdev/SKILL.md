# ER 画面光影与 shader(lookdev)

这份 skill 给的是动手前要有的知识:光在物理上怎么回事、行业里风格化游戏怎么做、URP 里对应哪些函数和开关、每种做法在手机上多贵。画面要什么样(四类光、暗部保饱和、不烘进底色这些口径)在 vault `013 美术/AI记忆/现行口径_场景光影与标定.md` 和 `现行口径_paintover与上色.md`,这里不重复。

## 头号规矩:不熟的技术先查资料再动手

勾哥点名要用的技术(他说「用 ambient occlusion」「烤那种散射阴影」),或者自己第一次做的效果,动手前先做三件事:读 `references/` 里对应那一页;页里没有的,上网查一手资料(论文、引擎源码、官方文档、做过同类游戏的团队的技术文章),查到的结论补进对应那一页;在标定件上做一个小实验,确认读到的东西在我们的工具版本里成立。凭已有理解直接改 shader、开一个引擎现成开关就交,是被勾哥连说三遍的做法。

查资料时分清三种来源并照实标注:读到原文的、自己实测的、自己推断的。推断的东西要么做实验验证,要么在交付里写明是推断。

## 每次交付前的五个取色自查

在游戏镜头截图上取色(用 reference-replicate 的 `refkit.py color`),一条不过就不交。原理和例外在 01。

1. 同一固有色的受光处和阴影处:阴影处色相要变(偏向环境光的颜色),不能只是变暗。
2. 遮蔽最深处和普通阴影处换成 HSV 比:明度降,色相基本不变,饱和度不降。饱和度往零掉,就是在最终颜色上乘了一层灰或黑。
3. 阴影色除以受光色,三个通道的比值不能相等。相等说明环境光是中性灰。
4. 受光但有缝的地方和背光的缝比:前者压暗的幅度要小得多。两者一样说明遮蔽在全力压主光。
5. 整帧去色后,地面、物件、角色三层的明度要分得开;同一材质的受光像素和阴影像素的明度分布不重叠。

## 实验脚本

`scripts/ao_lab.py`、`ao_lab2.py`、`ao_lab3.py`:后台 Blender 建一辆标定货车。一是换遮蔽距离、地面、合壳、采样数;二是两层叠加、归一化、带色遮蔽;三是第三层(竖直面的高度渐变)的五种来源和对参考的拟合。都出并排板和数字。学新的烘焙参数或换 Blender 版本时先跑它确认行为,再去烘正式件。用法:`<blender.exe> -b --factory-startup -P ao_lab.py --python-exit-code 1 -- <输出目录>`。

`scripts/unity_lookdev_lab.cs`:在 Unity 编辑器里验证 URP 的光照行为,不动打开的场景和工程资产。`unity command --timeout 240 script run --file <这个文件的完整路径> --entry LookdevLab.Run`,内存编译;它在预览场景里搭一个小场景,用 Mobile_RPAsset 和 Mobile_Renderer 的内存副本渲染(期间临时把 `QualitySettings.renderPipeline` 换成副本,结束时换回),按列表改阴影距离、软阴影档、环境光、SSAO 参数各拍一张,在已知的世界坐标上取色、量影边宽度,图和 `results.json` 写到系统临时目录的 `LookdevLab/`。跑之前确认编辑器不在 Play、不在编译;要验别的开关就在它的拍摄列表里加一行。换成自己的 shader 来验时改 `Mat()` 里的 `Shader.Find`。

## 工作纪律

- 改 shader 前先读它现在的全文,对着 02 的清单逐项核(缺哪些 pass、哪些关键字、遮蔽乘在哪),不在不了解的情况下加参数。
- 判一个改动有没有用,先看游戏镜头下的整图,再看数字。整图上看不出区别的改动不算改进,也不拿放大的局部和取色数字去说服人(调遮蔽反弹比例那次:取色差 0.06,先报成修好了、又报成改脏了,勾哥看整图是「看不出来不同」)。找下一步改什么时,把实拍和参考原图并排,从整图上最显眼的差距往下列,不从自己手上的参数出发。
- 光、遮蔽、shader 的改动一律在游戏镜头下同机位拍「改前 / 改后 / 参考」三联,附取色数字。开和关看不出区别的改动等于没做,要回去查原因而不是加大参数。
- 手机成本是硬约束:每加一种效果先在 04 查它的代价,能烘就烘,能在顶点算就不在像素算。
- 新学到的东西(读到的、实测的、踩的坑)当回合补进对应的 reference,下个会话才用得上。
- 05 到 10 里标〔推〕的配方(发光招牌不吹白、窗格连贯的反射、路面元素用哪种贴花、three.js 的换算系数、明度分带)都没有出处也没验证过,第一次用到时先在标定件上并排验,验完把〔推〕改成〔测〕。
