# 阶段 7:表情贴图 + 换脸材质 + 发光遮罩

## 7.1 方案和边界
Tripo 的脸是一整块网格,没有能张嘴的结构,硬做嘴型动画会很难看。做法是**换贴图**:把脸正面的多边形单独分一个材质,UV 指向一张 4×3 的表情图集,Unity 里改材质的 `_BaseMap_ST` 偏移就换表情(勾哥 10-07 同意)。

边界(提前说清楚):换贴图只改脸上画的东西,改不了脸的轮廓。"嫉妒鼓腮"在游戏里只有画出来的鼓起明暗和嘟嘴,脸颊轮廓不会真的鼓出来;要轮廓得另做形变,看效果再定。极端侧脸会有投影拉伸。

## 7.2 步骤
1. **渲底图 + 投影**(在最终的 rig blend 上渲,不在生成版 GLB 上,省掉坐标换算):
   ```
   F:/Apps/blender.exe -b --python scripts/blender/face_render.py -- --config <cfg>
   ```
   默认投影来自 Head 骨:中心 z = 头骨起点 + 0.41×骨长,正交尺寸 = 0.99×骨长(Wren 自动算出 0.8822/0.1629,和 10-07 手调的 0.8826/0.1633 一致)。
   **门**:打开 `face_calib.png`——眉、眼、嘴、下巴都在白框里,眼在绿带里,嘴在蓝带里。不在就 `--center-z/--scale` 重跑,并把值写回 config `face.center_z/ortho_scale`。投影存在 `face_projection.json`,后面的图集、UV、QA 都读它,不会对不上。
2. **画表情**(sol,并行):
   ```
   py -3 scripts/build_prompts.py expr --config <cfg> --input out/<slug>-tripo/face/face_front.png
   ```
   表情清单和描述在 config `face.expressions`(顺序 = 图集格子顺序,最多 12 个;第 0 个是 neutral = 底图本身)。**所有角色用同一套 11 个槽位**:neutral、blink、half、grin、happy、smug、jealous、angry、sad、focus、ko——Unity 的表情控制器枚举就是这个顺序,槽位名或顺序一变,游戏里会显示错格子(face_atlas.py 会警告)。角色差异只改每个槽位的**描述**:老角色(Harrow)按手册"情绪往里收",grin 写成收着的浅笑、happy 写成眯眼笑不露齿、jealous 写成不耐烦撇嘴,不要露齿大笑。
   **脸网格一变(重新生成/重新绑骨/改了脸型),所有表情必须照新底图重画**:画在旧脸上的表情会落到错的几何上。
3. **拼图集 + 对齐门**:
   ```
   py -3 scripts/face_atlas.py --config <cfg>
   ```
   sol 是整张重画的,像素差到处都有,没有意义;要看的是脸有没有挪位置。脚本对每张表情和底图做相位相关,量出平移:≤ 12px 自动配准(裁剪框跟着平移)并报数,> 12px 判 FAIL 重画。拿旧底图上画的表情套新渲的底图会差约 7px(Wren 实测),能配准,但最好重画。
   然后 Opus 看 `expr_contact.png`:画风和底图一致,眼睛在眼窝里、嘴在鼻子下居中,没有腮红贴片/符号/汗滴,一眼能读出是什么情绪,闭眼格真的闭上。
4. **换脸材质**:
   ```
   F:/Apps/blender.exe -b --python scripts/blender/face_swap.py -- --config <cfg>
   py -3 scripts/face_qa_sheet.py --config <cfg> --qa out/<slug>-tripo/rig/face_qa
   ```
   选面规则:法线朝镜头(n.y < -0.35;眼窝侧壁只在特征带里放行)、投影全在裁剪框里、多边形中心颜色不是头发色(config `face.hair_hue_ranges`)、从正面射线第一个打到它(没被刘海挡)、在特征带里按邻接再长 3 圈(眼角那些小三角形)。后脑保护只去掉**法线背向脸**的面。
   UV 写成"格子空间"(u 0..1,v 2..3),这是 Unity 里 WrenFaceController/CharacterFaceController 的约定:材质 tiling (0.25, 1/3),换格子只改 offset (0.25×列, −1/3×行)。10-07 是先写图集空间、再单独跑一遍 ×(4,3) 换成格子空间,漏跑就是整张图集贴在脸上;现在 face_swap 直接写格子空间(`--uv-space atlas` 留着备用)。
   **门**(Opus 看 `face_swap_qa.png` 原尺寸):
   - neutral:脸材质和头部其余部分之间没有接缝圈,眼嘴落在对的几何上;
   - 所有闭眼格(blink/half/happy/ko 的 2× 眼部裁图):**眼角零白色眼白/睫毛/旧嘴线残留**;
   - 3/4:额头脸颊上没有头发颜色;`headback.png`:后脑没有图集的颜色;
   - full_front、top70:俯视还读得出。
   眼角有残留就 `--grow 5` 重跑。**不要加"在脸中心后面 1cm 就删"的深度规则**:10-07 的后脑保护就是这条,删掉了 121 个脸侧/眼角面,已发货的 Wren 闭眼表情眼角全是白三角(本 skill 复查时渲出来确认过)。
5. **发光遮罩**(有发光件才做):
   ```
   py -3 scripts/emission_mask.py --config <cfg> --tex out/<slug>-tripo/rig/<Name>_basecolor.png --out out/<slug>-tripo/rig/<Name>_emission.png --preview out/<slug>-tripo/rig/emission_preview.png
   ```
   Wren:色相 140~185°、S > 0.3、V > 0.35,覆盖 3.4%,`_EmissionColor` (0.12, 0.42, 0.32)。预览里品红只能在发光件上(荧光绿外套必须在色相窗外)。贴图一换就重做。

## 7.3 出口门
`ATLAS_GATES PASS` + 表情看图门;`face_swap.json` 有选面数;QA 看图门全过;(有发光件)遮罩预览干净;`<slug>_rig_face.blend` 和覆盖后的 `<Name>.fbx` 在 rig 目录;`export_fbx.py` 复核 `FBX_CHECK PASS`。
