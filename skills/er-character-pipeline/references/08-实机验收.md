# 阶段 9:实机验收(游戏里真跑,不只看单独渲染)

单独渲染过了不代表游戏里对:枪大到挡住镜头、人又小又背对镜头这类问题,只有走真实流程才看得见。

## 9.1 前提
- 阶段 8 出口门全过;Hero.prefab 已本地替换(hero_swap + weapon_mount);
- `ucli.sh guard` OK,没有别的会话在 Play;
- Play 启动场景是 Boot(PlayModeSceneSelector 会把启动场景重置回 Boot;这正是我们要的真实流程)。

## 9.2 跑
```
bash scripts/unity/ingame_check.sh <Name> out/<slug>-tripo/unity/ingame
```
脚本里的按钮名(`Button_02`/`TabButtonContainer`、`PlayButton`、`Button_Deploy`)会随 UI 改版过时。日志里哪一步是 `none`,就在那一屏跑 `bash scripts/unity/ucli.sh buttons` 列出当前可点的按钮(名字、父节点、文字),换成新名字再跑;不要猜坐标点。

流程:Play(从 Boot)→ 等 25 秒到主页 → 底栏第二个页签 `Button_02`(父节点 `TabButtonContainer`)= 装备页 → 截图 → `PlayButton`(START)→ 简报室 → `Button_Deploy` → 等场景里出现 Expedition → 找 avatar 名含 Name 的 Animator → 截全屏 + 1440x2560 高清 → 抓 Console 错误(排除 Vivox/Chat 的已知噪音)→ **无论成败都 stop**(trap)。

状态截图已经在脚本里:出击后对每个状态(默认 `Sprint`、`death`、WeaponHold 层的 `HeroPistolRecoil`)把 Animator 定格在指定时刻截一张 `state_<名字>.png`,最后恢复。要换状态传第三个参数,例 `"Sprint:0:0.35,death:0:0.55"`;单独调试用 `ucli.sh eval scripts/unity/eval/anim_state.cs NAME=<Name> STATE=__layers LAYER=0 T=0` 列层。
这只是把动画状态定格来截图,证明不了"摇杆→移动"真的通;真操作要人或输入模拟,记为未验。

## 9.3 看什么(主会话 逐张看,裁局部放大,和旧主角并排)
装备页(gear.png):
- 角色大小合适、正面朝镜头(不对 = 缩放/转身没放在 Animator 层);
- 枪在手里、方向对、大小正常(巨大 = FBX 根缩放 100 的坑;歪 = WeaponMount 没换算);
- 没有挡镜头的灰黑大块;表情是 neutral,会眨眼(连拍两张能看到)。
远征(expedition_hi.png 裁角色周围):
- 俯视能认出是谁(头、识别件的剪影);脚踩在地上;
- 马尾/裙摆跟着动,没有横飞的"翅膀",裙子没有碎条纹;

## 9.4 这条管线管不到的,写进报告"欠账",不要说成做完
每次按工程现状核一遍下面几类,还没解决的照实列:
- **血条位置**:血条高度是场景里 UIHandler 上的固定偏移,对所有主角一样;压头顶要改得单独拍板(共享系统)。
- **握枪和开火**:持枪走 `HeroGunHoldPose`(枪带手 + 分枪型架势 + 两骨 IK,验收按坑 41 看手部特写和肘角);开火动作有没有按枪型做,以工程现状为准。
- **Tripo 预设动作**有没有逐帧 QA、有没有接进局内控制器(默认只用在预览,07 §8.8)。
- **受击等 Generic clip**:迁不到 Humanoid 的动作会失效。
- **原点多出的同名运行时实例**(没存进场景文件的)。
- 鼓腮等表情只是画出来的,脸的轮廓不变。

## 9.5 收尾(每次都做)

- 截图都在 `out/<slug>-tripo/unity/ingame/`,不在 Assets 里;
- Hero.prefab 的本地替换:按勾哥的落点决定留着还是 `git checkout` 回去(备份在 Assets/Temp/HeroOld.prefab 删之前先拷到 out 目录)。

## 9.6 站姿/动作自然度终审流程(勾哥定,为了不再四次返工)
1. 每个在用动作用 `eval/fullbody.cs` 出正/侧/背/3/4(900x1500),Wren 同机位同动作类型一组放旁边。
2. 逐张写清不自然的点,用这些词:脚掌俯仰(脚尖点地/脚跟离地)、膝距/踝距(交叉、内扣、罗圈)、手臂是否贴身、肘外弯、手腕折、手指僵、头倾/低头、躯干前倾后仰、朝向(正面是不是脸)。
3. 先量后改:Blender 源同一时刻的数字和 Unity 对比(`eval/knee_t.cs`、`eval/foot_probe.cs`)。源就这样 → 换源窗口或换动作;源对引擎错 → 骨架/导入问题,回 05 §6.8,不许在 avatar 上打补丁。
4. 派子 agent 改,改完同一组四视图复验,再进 Play 实机(装备页、空投舱、远征)截图。勾哥在 Play 时所有 eval 等 guard,中间态别让他看到。
