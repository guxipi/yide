# 10 部件换装(皮肤换发型 / 帽子 / 上衣 / 下装 / 鞋)

这一章解决"英雄出新皮肤时只换某几件,别的不动"。做法是:每个英雄有一个**冻结的底模**,脸是定稿脸,穿打底衣,头皮完整。新皮肤的每一件东西都从一次新的整身生成里拆出来、对齐、适配到底模上,底模本身永远不重生成。2026-10-26 在 Coda 上实测过上衣(夹克)和发型(卷发)两类,都能干净地贴回去。下装、鞋、帽子还没实测。

## 1. 为什么不能每个皮肤整身重生成

Tripo 每次整身生成,脸都会变。Coda 寸头版和 T 恤版用的是同一张脸的四视图,寸头版生成出来眉毛更粗更低、下颌更宽,左耳前还多了一块凸起。拿脸前部量:寸头版对 T 恤底模 mean 2.95 mm、p95 6.3 mm,同期夹克版只差 1.63 / 4.0 mm。脸是英雄的身份,手册定稿后不能随皮肤漂移。所以整身生成只当"部件来源",脸、手、身体永远取自底模。

Tripo 还会按总高把模型归一化。发型一变,总高就变,身体跟着整体缩放:Coda 寸头比卷发矮,身体大了约 1.65%(要缩到 0.9833 才对得上)。所以部件来源对齐到底模默认用**相似变换(带统一缩放)**,只用刚体时头顶会穿出 7.5% 的顶点。

## 2. 底模怎么来

**新英雄:先做寸头底模当定稿。** 照 01~05 章正常走一遍,只是建模四视图画成打底版:
- 上衣是贴身短袖 T 恤;下装和鞋先按英雄默认款画。下装、鞋要换的英雄,打底成什么样还没实测。
- 头发是 3 mm 寸头,发际线不动,轮廓不超出颅骨。头皮必须完整,这是发型能单独换的前提:Tripo 拆出来的头发只是一层表面壳,下面没有头皮。
- 脸型门和勾哥拍板都在这个寸头底模上过,过了就冻结。默认发型和默认外衣当第一批部件,按第 3、4 节做。

**老英雄(已有定稿模型、头发和头长在一起):剃头。** 用 `scripts/blender/head_shave.py`。定稿模型除头发区以外一个顶点都不动,头发区换成一次寸头生成的头皮。
1. 出寸头版四视图:sol edit 定稿四视图,只把头发改成 3 mm 寸头。结构参考图的 prompt 要写明"参考图里的旧头发一律忽略",写法见 `character-art-lab/out/coda-skin-test/mkstruct_buzz.mjs`。然后在 Tripo 生成整身、上 4K 贴图,共 50 点。这次生成只取头皮,脸变了没关系。
2. `part_align.py --bands 0-0.86` 把寸头整身对齐到定稿模型(相似变换)。
3. 准备定稿模型的头发三角形掩码。被头发围住的小岛要并进头发,否则删完头发后它们会悬在洞里。Coda 的掩码是从夹克版拆件的头发标签迁移过来的:定稿模型每个三角形的质心在拆件上找最近点,落在头发上且距离 < 0.5%H 就算头发。**没实测**:对定稿模型自己跑 Detailed 拆件,再用 `part_pick.py` 出掩码。
4. `head_shave.py --base <定稿> --hair_mask <npy> --buzz <寸头> --buzz_M <npy> --iters 80 --clamp brow --out <dir>`,做这几件事:
   - 先把"是不是头发"做成一个光滑场(Laplacian 扩散 80 轮)。
   - 定稿模型和寸头头皮都沿这个场的同一条 0.5 等值线精确切开,两边的切口是同一条光滑曲线。
   - 头皮边吸附到洞边后,用 `bmesh.ops.bridge_loops` 桥接,只对桥带和两侧一圈顶点做 3 轮平滑。
   - 钳制区只保护眉毛及以下;脚本按贴图自动找眉毛。
   - 每个桥面的 UV 从同一个 base 面取。

   Coda 实测(第六轮):开放边 0、非流形边 0;允许区(洞边一圈)以外的 base 顶点最大位移 0.0;接缝夹角 > 90° 的边 12 条(共 492 条)。

剃头走过的弯路,别再走:
- 沿头发三角形边界直接剪:洞边是锯齿,桥带翻折 59 条。
- 吸附后按位置焊接:两边顶点数是 109 对 273,焊不上,剩 375 条开放边,后颈透出一串斑点。
- 钳制区设成"脸前部且 z < 发际线":卷发在前额两角本来就垂到这条线以下,残片会留在底模上,回装时把头发顶出去 33 mm。
- 桥面 UV 取"最近洞顶点":会跨 UV 缝取到不同贴图岛,桥带上拉出深色碎条纹。

剃过的底模单独看(不戴头发)还不能见人:前额有一圈皮肤"头带",后颈和鬓角留着原来短发的凹凸。所以**老英雄的发型槽不能空**,寸头造型要当一个独立的发型件来做。

## 3. 上衣类部件(盖在底模上)

1. 出这件皮肤的四视图:在底模四视图上 sol edit,只改目标部件。
2. 出结构参考,在 Tripo 整身生成。设置和底模相同:H3.1、Ultra、贴图关、Triangle、200,000 面。再上 4K 贴图。
3. Tripo Segment 选 **Detailed**(40 点)拆件。拆件和整身同坐标(Coda 实测顶点误差 < 0.001%H),不用再对齐。一件部件总共约 90 点。
4. 对齐:`part_align.py`。只用和底模相同的区域参与 ICP。上衣皮肤用 `--bands 0-0.15,0.18-0.50,0.87-1 --pants-core`,即靴、裤芯和头。来源总高和底模相同时可以加 `--rigid`(Coda 夹克刚体对齐后,头/裤/靴 mean 0.15~0.21%H、p95 ≤ 0.54%H);总高不同就用默认的相似变换。
5. 挑部件:`part_pick.py --parts <部件名,…>`,输出来源整身的三角形掩码和部件 glb。部件号要在拆件里一块块看着挑。Coda 夹克共 12 块:衣身、上下两段袖子各两块、两个胸袋、拉链、领口/下摆/袖口罗纹。
   - Detailed 拆件会把相邻的东西混进来:下摆罗纹里混了腰带尖刺,领口混了脖子皮肤。加 `--clean-rib <罗纹件名,…>` 清理。在罗纹件里找"深色且 r ≥ b"(腰带、裤子)或"肤色"的三角形,只删和部件原始边界相连的色块;不连边界的深色块是罗纹槽的阴影,要放回;最后去掉 < 50 个三角形的孤岛。
   - 取色读 glb 里的原贴图,不要读 Blender `img.save()` 落盘的图:内嵌的 JPEG 会被重编码,逐像素最多差 53/255。
6. 贴回:`part_graft.py --margin 1.0 --snap`。
   - 删掉底模被部件盖住的面,但离部件边界 1%H 以内的保留,当裙边垫底。
   - 部件的边界环吸附到底模表面,衰减半径 2%H。
   - 底模在部件下面穿出来的顶点往里推 0.15%H,吸附后再推一遍。
   - Coda 夹克实测(清理过的掩码 69,130 面):删底模 46,358 面,组合 221,290 面。四条边界环吸附前最大缝 0.68~1.10%H,吸附后 ≤ 0.154%H;穿模顶点 789 → 10,最深 0.127%H。不清理的掩码缝更小,但下摆会带出腰带尖刺,不能用。组合后照常保脸减面到 58,000 面。
7. 之后照常绑骨(05)、入库(07)。**没实测**:换装件绑骨后的形变,以及 Unity 里按槽位挂件。

## 4. 发型类部件(叠在底模外)

来源的做法和上衣一样(整身生成 + Detailed 拆件 + `part_align.py --bands 0-0.86`),不同的是这两步:
- **挑头发**:`part_pick.py --parts <头发块,…> --band-from <头部件> --band-zmin 0.90 --band-lum auto --base <底模> --M <来源→底模矩阵>`。拆件里的头发块全取。头部件里还常混着一圈头发带,按"z > 0.90H 且贴图近黑"挑出来,再按连通块只留和已选头发块相接的部分;漏掉连通块这一步,眼睛和眉毛也会被挑进来,贴回后正脸出现两套眼眉。auto 阈值取亮度直方图里近黑峰和皮肤峰之间的谷,Coda 读原贴图时是 L < 0.235。
- **适配**:`part_fit.py --clearance 0.25`。底模不动,只推头发。
  - 对每个头发顶点,算它到底模头皮的有符号距离 sd。目标间隙 c = 0.25%H,位移 δ = max(0, c − sd) × 头皮外法线,只推不拉。
  - 所有头发块先按位置焊接,再一起平滑位移场:uniform Laplacian 10 轮,λ = 0.5,每轮长度不小于原 δ。这样块与块之间不会裂开。
  - 平滑会把位移方向带偏,所以最后补推 3 轮:sd < 0.9c 的顶点沿当前法线补到 c。

Coda 卷发实测(10-26)。"头发像素里露出头皮"是指原版里是头发的像素,装回后变成了头皮:

| | 寸头底模,刚体 | 寸头底模,相似变换 + 适配 | 定稿底模剃头 + 适配(第六轮) |
|---|---|---|---|
| 头发顶点在头皮里 | 头皮穿出 7.5% | 0% | 0% |
| 头发像素里露出头皮,背/侧/顶视 | 3.8~13.2% | 0~0.64% | 0~0.66% |
| 同上,正面 / 仰视 20° | 7.5% / 12.2% | 3.9% / 8.8% | 1.7% / 4.7% |
| 头发剪影 IoU(对原卷发) | — | 0.973~0.999 | 0.970~0.999 |

适配时约 14% 的头发顶点被推,最大位移约 10 mm,全部头发顶点平均位移 0.7~0.8 mm,肉眼看不出变化。寸头底模那一列正面残留多,是因为那次生成换了脸、额头挡在头发前面;剃头那一列的脸是定稿脸,残留少。剃头版前额还有一排锯齿,那是头发件下沿本来的几何:原版里锯齿后面是深色贴图,看不出来,剃头后背景换成了肤色就露出来了。

## 5. 槽位(10-26 勾哥定)

一共五个槽,每个都能单独换:**发型、帽子、上衣、下装、鞋**。连体件(长风衣连裤、连体服、一体靴裤)一件占多个槽,穿上时把它所占槽里原来的件全部摘掉。帽子和发型同时存在时,按帽型决定发型件是隐藏还是压扁,这条还没实测。

英雄默认造型 = 底模 + 默认发型件 + 默认上衣/下装/鞋件。新英雄的底模打底衣和寸头会在对应槽摘空时露出来,所以要过贴图门。老英雄剃过头,发型槽不能空(见第 2 节)。

**没实测**:下装、鞋、帽子的拆件贴回;Unity 里的槽位挂件和数据结构(现有 `HeroSkinService` 只支持整套换模型,`ClientBalance.CosmeticSkins` 一行只有一个 OutfitPrefabId)。

## 6. 脚本

都在 `scripts/blender/`,用法写在各自文件头,都打印一行 `XXX_DONE` 加 JSON 报告。四个 part 脚本在 Coda 数据上复跑,和实验数字逐项对上(取色那一项见第 3 节第 5 步)。

| 脚本 | 做什么 |
|---|---|
| `part_align.py` | 来源整身 → 底模 ICP,默认相似变换,`--rigid` 退回刚体,`--bands` 选参与区 |
| `part_pick.py` | 从 Detailed 拆件挑部件,出整身掩码和部件 glb;`--clean-rib` 清罗纹,`--band-from` 抠头发带 |
| `part_graft.py` | 上衣/下装类贴回:删被盖面、留裙边、边界吸附、推穿模 |
| `part_fit.py` | 发型/帽子类适配:只推不拉、焊接后平滑、补推 |
| `head_shave.py` | 老英雄剃头:光滑场等值线切开、桥接寸头头皮 |
