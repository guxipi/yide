# 阶段 1:建模四视图(平光厚涂版)

这套图有两个用途:给 Tripo 上贴图(阶段 4),和作为结构参考图的底(阶段 2)。它**不是立绘**,也不是角色表。

## 1.1 和立绘的区别(硬规则)
- A-pose,双臂离身 35~40°,手里什么都不拿,手不碰身体。
- 嘴闭着带一点笑,**不露齿**(露齿会把牙烤进贴图,表情交给阶段 7 的换脸)。
- 背景整张纯平 #8A8A8A,零阴影、零地线;全包围柔光,无投影、无明暗交界线、无 rim、无高光。
- 颜色自带厚涂笔触(每块色 2~3 个相近色阶,mo.co albedo 那种),几何干净。不描边、不赛璐珞、不塑料、不刻面、不迷彩、不布纹、不毛孔、不腮红。
- 头身比**按各角色手册定**(Rook 模型 5.5 头身,头约占总高 0.18~0.19;Vesper、Harrow 6.5 头身,头约 0.15;其余看各自手册),头量的是发顶到下巴,不含马尾/帽檐。阶段 0 先问清,写进配置 `sheet.head_ratio`,不要沿用上一个角色(见 pitfalls 58、91)。配置示例里的 0.20~0.22 是 Wren 自己的比例,不是默认值。
- 识别件按定稿图原样画,只许"为重建删悬空件、把细件加粗"。**不许改识别件的大形**:Rook 第 4 轮把背包绳袋、头盔、鞋带简化掉被打回;Wren 第一版把圆柱玻璃罐画成方盒被打回。
- 发光件(Wren 的罐子)只画成自身颜色,零 bloom、零溢光到身上。
- 不对称件写清楚"角色自己的哪一侧",并写出它在每个视图画面的哪一侧(front 视图里角色右边 = 画面左边)。
- 手势先过"有没有现实政治/宗教含义"(例:黑人角色不出举拳)。A-pose 一般没问题,改姿势时注意。
- **体态特征(驼背、前倾、歪站)不要画进建模图**,建模图里脊柱要直、头要正。原因:Unity Humanoid 的 Enforce T-Pose 会把脊柱当成直的参考,动画一播,画进网格里的驼背会被拉直;体态要靠动画层/脊柱肌肉偏移做(要不要做、怎么做问勾哥)。建模图只保留体态带来的**比例**(宽肩、肩往前的体积)。
- **背在身上的识别件武器**(Harrow 背后那支比人还长的枪):按识别件画进建模图,做成一整块实心(绑骨时整块挂一根 rigid 骨)。游戏里手上拿的是按枪型的通用枪模型,两把枪会同时出现——画之前先问勾哥这支背枪留在模型里还是做成单独的挂件。

## 1.2 步骤

1. **写中文 spec**:复制 `templates/fourview/spec_template.md` 到 `{workspace}/prompts/<slug>-tripo-spec.md`,按手册逐件填。写"身份记号逐视图可见表"。
2. **写英文角色块**:照 `templates/fourview/character_block.wren.txt` 的写法,一件一段,写颜色 hex、形状、尺寸关系、哪些要加粗、哪些删。存成 config `fourview.character_block` 指向的文件。config 里同时填 `proportion_notes / face_notes / identity_markers_en / view_notes(四个视图)/ volume_list / eye_style`。
3. **front 第一轮(3 张)**:
   ```
   py -3 scripts/build_prompts.py fourview --config C:/.../configs/<slug>.json --view front --round r1 --n 3
   ```
   它打印三条 `sol_image.sh` 命令。并行跑:在**同一个 shell** 里每条后面加 `&`,最后 `wait`(写成 `( ... & )` 会把进程秒杀)。参考图:图 1 = 定稿图,图 2 = 已定稿角色的建模 front(只拿格式,prompt 里写死"一根毛都不许拿")。
4. **front 自检**:
   ```
   py -3 scripts/sheet_check.py --config <cfg> --view front out/<slug>-tripo/sheet/<slug>-front-r1-*.png
   ```
   看三样:脚本门(画高 0.85~0.95、脚下无阴影、腰线 ≥3 段=手离身)、对照板 `check/<slug>-front-contact.png`、每张的头部刻度图 `*-head.png`(读发顶到下巴占 bbox 高的比例,要落在配置的 `head_ratio`;bbox 顶常常是发圈/帽子顶,不是发顶,自己从发顶读)。
5. **改头身比 / 修件**:用 edit 模式喂选中的那张(不是重新文生图):
   ```
   py -3 scripts/build_prompts.py edit --config <cfg> --view front --input <选中>.png --fixes fixes.txt --round r2 --n 3
   ```
   fixes.txt 一条一改。**头身比一次只要求放大 10~12%**:sol 按文字只给 6.3~6.5 头身,写"放大 25%"会一步跳到 4.7(Rook、Wren 都是这样),没有中间值。同一轮可以顺手修多件(Wren r2 同时修了头身比、罐子颜色、多余口袋盖、靴筒刻面)。
6. **脸型门**(front 定稿前必须过):脸是家族脸——圆、U 下颌、短圆下巴、眼睛在脸正面、粗上睑线、无长睫毛。不是就跑 `faceround --view front`(图 2 = 定稿图脸部特写)。**改脸结构时不要喂旧版本当参考**:旧版会把脸锁回去(Wren 脸、Norm 下巴两次踩实),身份全靠文字锁。
7. **侧面和背面(各 2 张)**:图 1 = 选定 front,图 2 = 定稿图,back 加图 3 = 俯视图(只看背面装备)。
   ```
   py -3 scripts/build_prompts.py fourview --config <cfg> --view left --input <front定稿>.png --n 2
   ```
   right、back 同理。自检加朝向门:left 脸朝画面左(肤色质心偏移 < -0.10),right 朝右(> +0.10),back 近 0。
   侧脸也要过脸型门:用 `crop_compare.py --save-crop` 裁头(例 400x400 框)→ `faceround --view left --input 头裁图 --ref 新 front 头裁图` → `sheet_paste.py` 贴回(羽化边)→ 再进 finalize。
8. **识别件对照表**(主会话 自己写进日志):逐件 × 逐视图,"在/不在/形状对不对",外加不对称件的侧别。用 `crop_compare.py --box ... --out` 把每件的局部和定稿图并排看,不要对着 prompt 打勾。
9. **颜色差先量再改**:看着"偏青/偏暗"时先 `crop_compare.py --hsv` 量两张的 H/S/V 中位数。Wren front 罐子"偏青"实测色相和侧面一样(161°),差在饱和度和明度。真是色相问题才用 `sheet_finalize.py --hue-fix`。
10. **定稿**:
    ```
    py -3 scripts/sheet_finalize.py --config <cfg> front=... left=... back=... right=...
    py -3 scripts/sheet_check.py --config <cfg> --final out/<slug>-tripo/final/<slug>-tripo-{front,left,back,right}.png
    ```
    finalize 只把**和画布边连通**的背景填成 138(人物内部的灰不动),裁 bbox、缩到画高 0.88、水平居中、鞋底同一条线。
11. **识别件有新要求时**(勾哥看了候选又提):用 edit 喂 final,只换那一件,四个视角并行(Wren 换圆柱罐就是这样一轮过的)。
12. **同一件东西出了两种可行画法**:做对照板给勾哥点,不许自己挑。

## 1.3 出口门(全部满足才进阶段 2)
- `sheet_check.py --final` 打印 `ALL_NUMERIC_GATES PASS`(四角精确 138、std 0、画高 0.880±0.005、脚下无暗像素);
- 头部刻度图上头身比落在配置的 `head_ratio`(按角色手册定),四张头大小一致(漂移 ≤ 0.01);
- 识别件对照表全"在且形状对";不对称件四个视图侧别都对;
- 脸型门过(front + 两个侧面);
- 无文字/数字、无溢光、手里无物、嘴闭着。
- 定稿四张 + contact 拷进 vault `img/建模四视图/expedition_<Name>建模四视图_{front,left,back,right}_1024x1536.png`(覆盖前把旧版挪进子文件夹,例 `旧版_尖下巴_2026-10-07/`)。

## 1.4 常见失败 → 修法
| 症状 | 原因 | 修法 |
|---|---|---|
| 头比 `head_ratio` 小(常见是出成立绘比例) | sol 按文字给立绘比例 | edit 喂上一张,"enlarge head 10-12%";差得多就直接写目标数字(见 pitfalls 81、92) |
| 同上,edit 两轮后还差 ≥0.02 | sol 每轮只给目标差 1/3(坑 117) | **mock 法**:PIL 以领口顶为轴把身体缩小到目标比(头不动),再 edit 只融合领口接缝;侧背视图以领口/肩线对齐 front 同法(坑 118);量法 `tools/vesper_cur_headmeasure.py` |
| 识别件被简化成别的形状 | spec 里写了"简化",模型自由发挥 | spec 写"形状照定稿图原样,只删悬空件",逐件写形状词(圆柱/炮口/厚环) |
| 侧面朝向反了 | 视图块没写 FACING CHECK | 用 views.json 的模板(已写),朝向门不过就重出 |
| 侧面和 front 不像一个人 | 侧面没喂选定 front | 图 1 必须是选定 front |
| 改脸没改动 | 喂了旧版本 | 去掉旧版,只用文字 + 定稿图特写 |
| 背景有渐变/脚影 | 生成时就有 | finalize 会填背景;脚影门不过就重出(finalize 不擦人物下方的阴影) |
| 帽子/布料出迷彩或刻面 | 默认风格回潮 | spec 里对每块布单写"禁迷彩禁刻面" |
