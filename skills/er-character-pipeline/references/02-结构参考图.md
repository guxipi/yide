# 阶段 2:结构参考图(给 Tripo 建形状用)

## 2.1 为什么要两套参考图
2026-10-07 Wren 第一版模型脸是"蛇精脸":正脸平、眼窝深、下巴削成 V。根因不在 Tripo,在参考图:平光四视图没有任何明暗,Tripo 只能靠轮廓线猜脸的深度,于是照日系大眼的画法把脸推成平面、把眼窝挖深、把下巴削尖。

解法是把参考图拆成两套,分别喂 Tripo 的两步:
- **结构参考**(本阶段):把定稿四视图重画成带柔和体积光的结构图,脸颊、下巴、鼻梁、头骨都有明暗,头发从脸颊和下颌线上拨开。**只用来生成白模**(Tripo 关贴图)。
- **平光厚涂四视图**(阶段 1 的定稿):在 Tripo 贴图页单独上贴图,笔触和原画一致,结构图里的明暗不会烘进贴图。

只喂平光图 = 蛇精脸风险;只喂结构图 = 明暗被烘进贴图、Unity 里再算一遍光(脏)。两套都要。

## 2.2 步骤
1. 每个视图一条(四条可并行):
   ```
   py -3 scripts/build_prompts.py struct --config <cfg> --view front --input out/<slug>-tripo/final/<slug>-tripo-front.png
   ```
   config 里 `fourview.volume_list` 写这个角色要强调体积的部件(Wren:裙褶、靴子、圆柱罐;Harrow 应写:驼背的肩背、马甲、长枪、帽子)。`face_notes` 写年龄特征(老人:皱纹只画结构,不画成刻面)。
2. 轮廓一致性门:
   ```
   py -3 scripts/silhouette_iou.py out/.../final/<slug>-tripo-front.png out/.../struct/<slug>-struct-front.png --out iou_front.png
   ```
   IOU ≥ 0.93 才收(拨开头发会改几个百分点;再低说明 sol 改了身形,Tripo 会建出和贴图对不上的身体)。
3. 主会话 看图门(四张都看,和平光版并排):
   - 头是正常的圆颅骨,脸颊有肉、下巴短圆,侧面能看到鼻梁、嘴唇、圆下巴和下颌到脖子的过渡;
   - 眼睛是"脸面上的眼睛"不是"洞"(没有大块实心黑眼线);
   - 头发没挡住脸颊和下颌线;
   - 身体、服装、识别件、颜色和平光版一致;无投影、无 rim、无高光、无文字。
4. 存档:拷到 vault `img/建模四视图/结构参考_给Tripo建形状/expedition_<Name>结构参考_{front,left,back,right}_1024x1536.png`。**上传 Tripo 时从 vault 路径传**:浏览器上传工具读不到 `character-art-lab`(10-07 被权限拦过),vault 路径能读。

## 2.3 出口门
四张 IOU ≥ 0.93;脸部结构门四张都过;已存进 vault。

## 2.4 常见失败
| 症状 | 修法 |
|---|---|
| sol 顺手改了衣服/配色 | prompt 已写"keeping the exact same ...";再出一张,别手修 |
| 光太硬出明暗交界线 | 重出,强调 soft key light + ambient occlusion |
| 头发还是糊在脸上 | 重出,把 "pull strands off cheeks/jaw" 放在第一条 |
| IOU 低于 0.93 | 看 diff 图哪里多/少,多半是马尾或背包被挪了,重出 |
