# 阶段 5:模型验收门(白模形状门 + 贴图门 + 脏贴图清理)

原则:**几何问题看灰模,贴图问题看不打光的纯贴图**,两种都要从游戏会用的角度看(正面、侧面、3/4、70° 俯视)。只看带贴图带光的渲染,两类问题会互相遮掩。

## 5.1 白模形状门(阶段 3.1 之后)
```
F:/Apps/blender.exe -b --python scripts/blender/clay_face.py -- <geo.glb> out/<slug>-tripo/check/clay_geo
F:/Apps/blender.exe -b --python scripts/blender/render_views.py -- <geo.glb> out/<slug>-tripo/check/geo --mode clay
py -3 scripts/compare_board.py --refs out/<slug>-tripo/final --ref-prefix <slug>-tripo- --renders out/<slug>-tripo/check/geo --out out/<slug>-tripo/check/geo_board.png
```
看(Opus,和定稿图、结构参考、上一版白模并排):
- **脸**(clay_front/left/34/top70/under):正脸圆、U 下颌、短圆下巴;侧面有鼻梁、嘴唇、圆下巴,脸颊向前鼓;眼睛在脸正面,眼窝浅;70° 俯视脸不收成 V;仰视没有深洞。Wren gen-2 的眼窝仍偏深,但换脸贴图盖住、俯视看不出,接受了——同类情况记进日志,不算卡点。
- **剪影**:识别件大形对(圆柱就是圆柱、炮口有空洞、底环在、马尾是两个水滴大块、裙子大褶、靴扣在)。
- **几何**:无"肉肠"节(Rook 裤子)、帽檐/罐盖有厚度不是纸片、手指分得开、细件没糊成团、脸不塌。
- 面数:60k 档实际约 5.8 万三角(Wren 58347),手机端可接受;超过 10 万要先问。
不过:回 3.1 改选项重试(最多 3 次);三次都不过,回阶段 2 改结构参考(通常是头发挡脸或光太平)。

## 5.3 脏贴图清理(在 **rig GLB** 上做,阶段 6 绑完骨之后)
贴图属于网格的 UV。Tripo 每次导出/绑骨都可能换 UV,所以:**哪个网格要进游戏,就在哪个网格的贴图上清理**;换了网格(重新生成、重新上贴图、重新绑骨),旧的干净贴图作废,重做。10-07 拿 gen-1 清好的贴图套 rig 网格,后脑勺出了肤色斑和黑洞,最后只能手臂用清过的、其余用原图拼。
```
F:/Apps/blender.exe -b --python scripts/blender/tex_extract.py -- <rig.glb> out/<slug>-tripo/tex
py -3 scripts/tex_clean.py --mesh out/<slug>-tripo/tex/mesh.npz --tex out/<slug>-tripo/tex/basecolor_orig.png --out out/<slug>-tripo/tex
```
规则(脚本里):三角形按平均色在 CIELAB 里判皮肤(色相 35~62°、彩度 > 30、L > 40),吞掉被皮肤包住的小岛,再往手臂区里相邻的深灰褐三角形长 8 圈(脏块本身过不了皮肤色判断);头部(z > 0.76)和手不碰;在皮肤纹素上找"比周围皮肤暗 + 比同亮度皮肤更灰"的块,强种子 + 弱扩张;用 push-pull 从干净皮肤插值填,再从最近的干净块搬高频细节,羽化,不越过非皮肤三角形。

门:
- `dirt_flags.png`(品红 = 要填的):只落在皮肤脏块上,不在衣服、眼睛、嘴、手指缝上。覆盖率 > 皮肤纹素 15% 说明规则抓到了正常颜色,停下收紧参数(`--k-hi/--dmin-hi/--g-hi`)。Wren gen-1(8K):默认参数 1.8%,手肘大脏块清掉,只剩手肘下一点淡灰(和 10-07 人工结果一致)。
- 前后对比:`render_views.py ... --texture out/.../tex/basecolor_orig.png` 和 `--texture .../basecolor_clean.png` 各渲一次手臂特写,`compare_board.py --row` 并排看。
- 清理结果用在 `rig_build.py --texture out/<slug>-tripo/tex/basecolor_clean.png`。
