# 阶段 0:首次接手、输入和事实核对

## 0.1 首次接手 checklist(每个新角色、每台新机器都过一遍)

逐条做,做不到的停下来问,不要带着问号往下跑。

1. **读真源**。角色手册 `013 美术/角色手册/<Name>角色手册.html`、定稿图、俯视图、表情表。人物设定以 Google Sheet 人物表(1351H8,militarypineapple 账号)为准,手册和表冲突听表的。记下:识别件(换皮也不能动的东西)、不对称件在哪一侧、签名色、体态、年龄、表情分寸。
2. **看有没有半成品**。vault `013 美术/角色手册/img/建模四视图/` 里有没有这个角色的旧四视图、结构参考;`character-art-lab/out/<slug>-tripo/` 有没有旧轮次。旧东西只做参考,不要直接喂给新一轮(会锁脸、锁姿势)。
3. **先定生成面数**。手册头身 ≥ 6(head_ratio 上限 ≤ 0.17)的角色,阶段 3 整身一次生成 200,000 面,上贴图后用 `scripts/blender/protect_decimate.py` 保脸减面到 58,000(10-26 Coda 验证,见 SKILL 总纪律、坑 116);Wren 这种 ≥ 0.20 的照旧 6 万面直出。不再默认分头换头。
4. **建配置**。复制 `templates/char_config.example.json` 到 `{workspace}/configs/<slug>.json`,先填 name/slug/out_dir/design/identity_items/fourview 段,rig/face/unity 段等对应阶段再填。所有脚本都只认这个文件,不改脚本里的路径。
5. **环境自检**(一次性,结果写进本次日志):
   - `F:\Apps\blender.exe -v` 能跑(5.1);`py -3 -c "import PIL,numpy,scipy,cv2"` 不报错。
   - `codex --version` 能跑;权限里有 `Bash(codex exec:*)`。自动模式下没有这条规则,sol 的活会被直接拒掉,不会弹窗。
   - `bash scripts/unity/ucli.sh status` 能回 playMode。连不上先 `unity pipeline list` 看 Server Reachable。Coplay 只做备用。
   - 浏览器:到阶段 3 再验身(见 03),现在不用开。
6. **问清落点**(勾哥拍):这个角色进游戏是替换主角(Hero.prefab)、可选角色、随行 NPC 还是只进基地。验收时可以先本地替换 Hero.prefab 走最严的路,但**不提交 Hero.prefab**,除非勾哥明确说要。
7. **开工前 `git fetch` 看 origin/main**(多台机器并行,别和另一台撞车);Extraction 直接在 main 上工作,先确认分支。不 commit、不 push,除非勾哥说。
8. **确认 Unity 没人在用 Play**。另一个会话在 Play 时:不写 .cs、不切场景、不进 Play。阶段 8/9 前再查一次。

## 0.3 分工和成本

- **sol(gpt-5.6-sol,经 codex CLI)**:出图、改图(四视图、结构参考、表情)。也可以把"跑脚本+按清单迭代配置"的活派给它(`templates/sol/*.txt`)。
- **Opus(本会话)**:写 spec、跑脚本、看对照板、决定返工、操作 Tripo 网页和 Unity。验收只认自己看过的图和脚本输出,sol 的"pass"不算。
- **Fable**:只在审美拍板或诊断卡死时短用,问题写死,要结论。
- **勾哥**:识别件形态有歧义时、同一件东西有两种画法时(做对照板给他点,不许 AI 自己挑)、落点和提交。

**点数预算**(Tripo 网页,2026-10-07 实价):结构白模 30(Ultra 开、贴图关)+ 贴图页 4K 20 + 自动绑骨 20 + 预设动作重定向 0 = **每个角色约 70 点**;每次重试按同价再算。Wren 实际花了约 170~200 点(含第一版带贴图生成、两次绑骨、探路)。点数不记不对账(10-24 勾哥定)。

**时间**:Wren 从四视图到实机约 12 小时(大量是踩坑)。按本 skill 走,目标半天:四视图 2h、结构参考+Tripo 1h、绑骨 1h、表情 1h、Unity+实机 1.5h。
